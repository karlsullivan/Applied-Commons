This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

A fully-featured open-source ICU ventilator from the non-profit RespiraWorks (200+ contributors), explicitly 'optimized for manufacture using commonly available components and free to license,' with public mechanical, electrical and systems design, software, manufacturing notes and bill of materials. It provides open repair and build access for critical life-support clinical equipment. Mature, multi-year engineering program with regulatory and QA documentation.
