This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source knitting software suite (kniteditor, knittingpattern exchange format, AYABInterface for All Yarns Are Beautiful machines, circle-knitting) to design garments and knit them on DIY knitting machines. For makers producing clothing locally; mature and actively maintained (~1500 stars, downloadable releases, knitlib updated 2026).
