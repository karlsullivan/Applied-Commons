This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source community-communications / offline phone and mesh project (core daemon 'serval-dna' implements Distributed Numbering Architecture, mesh messaging and related protocols) for peer-to-phone connectivity without carrier infrastructure, descended from the university 'Batphone' work. Real, published code on GitHub (serval-dna ~177 stars, homepage servalproject.org). Note for scoring: core repo last pushed 2022, so maturity/activity is lower than the newer candidates — included for its offline-mesh-telephony capability rather than as a current primary recommendation.
