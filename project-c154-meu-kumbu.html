This project is discovered: Applied Commons has catalogued it but has not written a build pack for it.

Self-hosted wallet / mobile-banking app template (~71 stars, last push 2024) — a starting scaffold, not a turnkey platform, for building a community wallet/mobile-banking app. Included as the most-complete public mobile-money app template. CAVEAT: license is a custom NOASSERTION, so a local maintainer must verify the terms before forking (relevant to the 'open licenses, no vendor lock' constraint). Cold-climate viable (software).
