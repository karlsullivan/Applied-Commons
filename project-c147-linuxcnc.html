This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Mature, free, open-source CNC machine-control software (GPL, active community) with no license fee; widely used to retrofit and repair existing machine tools so old or failed equipment becomes controllable again. A core piece of open fabrication that lets trained operators make and repair metal/wood/plastic parts locally instead of waiting on OEM service. Cold-climate workable (indoor control software). Not in already_known (Grbl is a different controller).
