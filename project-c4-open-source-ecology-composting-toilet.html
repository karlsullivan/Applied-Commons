This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Above-ground moldering composting toilet for large groups (workshops/interns), decomposition in an insulated straw-bale chamber with ventilation; 8-12 month moldering cycle. Open-source (CC-BY-SA 4.0). Based on Nancy Rosalie's Common Throne at the Common Ground Fair in Unity, Maine — cold-climate (Maine zone 6); designed for seasonal group use.
