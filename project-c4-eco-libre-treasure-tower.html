This project is discovered: Applied Commons has catalogued it but has not written a build pack for it.

A 6-story zero-waste recycling station that bundles 6 dry composting toilets, urine collection, a handwashing station, rainwater collection and anaerobic (200L drum) storage for human-waste decomposition, all barrier-free with a spiral ramp. GPL v3 or later / CC-BY-SA 4.0, with CAD screenshots. A complete, multi-need, locally buildable hardware design; early-stage documentation.
