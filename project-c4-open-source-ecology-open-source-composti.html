This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open Source Ecology's improved-pit-latrine-style composting toilet: ventilation + agitation + sawdust addition + liquid separation to achieve composting and produce humanure. Open-source (CC-BY-SA 4.0). Page is a stub (Basics section only) — lower documentation maturity than the main Composting Toilet page.

References

  1. Composting Toilet (2014 design) - OSE wiki: above-ground moldering composting toilet in isolated straw-bale chamber for large groups over a short term (Oct 1 - Jun 1), based on Nancy Rosalie's Common Throne; 5-gallon bucket seatboxes per Humanure Handbook (Factor e Farm); 'Work Still Needed' incl. instructions for use/cleaning; plans via SketchUp + Dozuki wiki.opensourceecology.org
  2. Open Source Pit Latrine - OSE wiki: sealed pit with seat stalls; 'must be periodically emptied, preferably by an Open Source Vacuum Truck' wiki.opensourceecology.org
  3. USDA Forest Service, 'Composting Toilet Systems: Planning, Design & Maintenance' (B. Land, 1995) - field review of existing compost toilets, digester sizing, site selection, health/safety, maintenance fs.usda.gov
  4. Anand & Apul, 'Composting toilets as a sustainable alternative to urban sanitation - A review', Waste Management (2013) - review of composting toilet design/operation and the temperature-time criterion for safe compost sciencedirect.com
