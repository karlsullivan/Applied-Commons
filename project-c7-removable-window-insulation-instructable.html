This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open removable window insulation (CC BY-NC-SA 4.0, 6 steps) using reflective bubble radiant-barrier insulation with Velcro and clear tape; tools are tape measure, scissors, and ruler. Helps cold-climate households reduce winter-night heat loss and cold spots, and the panels come off in summer so it spans seasons. Passive, no power. Mature: published 2024, featured winner, ~19K views, with a full bill of materials and build steps.
