OASYS open-source aquaponics (YWAM Emerge)

OASYS open-source aquaponics (YWAM Emerge)
NeedFood and nutrition
StatusScreened
LicenceNone found
Climatestropical, arid, temperate
This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open, 'affordable, robust, simple-to-build, high-output' aquaponics system deployed in multiple countries (incl. a ~10 m x 15 m greenhouse build). Design: 3 IBC fish tanks with independent shut-offs, dual pump for independent water and aeration, radial/Matala/biological filtration, 6 grow beds with independent shutoffs. Free starter packet with step-by-step build instructions and a full parts list is offered; the complete manual is provided through OASYS training. Mature (built in several countries); tropical-focused rather than cold-climate.
