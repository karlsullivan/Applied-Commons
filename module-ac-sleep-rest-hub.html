This is a draft module. It has not been built or tested.

Local, cloud-free hub that ingests the standard sleep episode from the wearable tracker, the actigraphy engine, the wrist node and the family tracker; runs the actigraphy engine for circadian metrics; schedules the gentle wake alarms to the wake window; and publishes the sleep-environment temperature log. The 'one row per episode, one table per person' aggregation and dashboard layer that makes the other modules interchangeable, with a durable local record that survives a power cut. Local MQTT transport is an implementation detail (reuses the commons local-telemetry convention) and is not declared as a new standard.
