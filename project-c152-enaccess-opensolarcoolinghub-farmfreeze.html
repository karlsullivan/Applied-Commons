This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source, solar-powered IoT cold-room 'cooling hub' (architecture + electronics + IoT + solar engineering) for off-grid food and medicine storage; locally buildable and low-cost. Hardware is CERN-OHL v2 (strongly reciprocal), firmware MIT, docs CC-BY; repo active as of July 2026 (created 2025, continuous pushes, public docs site). Directly targets the brief's off-grid refrigeration and cost-gap requirements with local materials. Underpins the EnAccess FarmFreeze off-grid solar cold room.
