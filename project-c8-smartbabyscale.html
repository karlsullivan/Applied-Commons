This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source (MIT) IoT neonatal monitoring scale that scores illness severity via SNAPPE-II, trained on MIMIC-III data (XGBoost on a Raspberry Pi); turns routine newborn weighing into a non-invasive risk checkpoint. Thesis/prototype maturity, public code.
