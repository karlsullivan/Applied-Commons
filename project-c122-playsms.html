This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source web interface for SMS gateways and bulk/broadcast SMS (GPL-3.0, 894 stars, actively maintained). Front-ends gateways such as Kannel to send and receive SMS over basic phones, with scheduling, groups and bulk dispatch. The practical tooling layer for the food/income requirement: delivering market-price and crop-advisory SMS to smallholders.
