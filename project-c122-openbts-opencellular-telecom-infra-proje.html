Open-source cellular infrastructure. OpenBTS is open-source software that replaces proprietary base-station hardware with an IP-based, flexible architecture (including the first open-source 3G/UMTS stack). OpenCellular, a TIP project group whose hardware and software files were open-sourced (with Facebook), targets 'connect the unconnected in rural areas' with sustainable community cellular, low total cost of ownership, local build/maintain, and an OpenCellular grant program for rural deployments. Mature community/research projects; addresses the low-cost cellular backbone so feature phones can reach the last mile.
