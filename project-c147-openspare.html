This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source library of replacement parts for appliance repair, licensed under the CERN Open Hardware Licence v2 (Weakly Reciprocal): free KiCad PCB source files (schematics, board, Gerbers, BOM) that anyone can reuse, modify and manufacture. It is explicitly positioned as an open, affordable alternative to OEM-only spare parts, directly attacking the repair monopoly. 3D models are in progress; the project is young but licensed and structured for local manufacture.
