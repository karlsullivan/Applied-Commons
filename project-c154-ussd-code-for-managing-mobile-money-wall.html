This project is discovered: Applied Commons has catalogued it but has not written a build pack for it.

Reference USSD code for managing mobile-money wallets e.g. Ecocash in Zimbabwe (Apache-2.0, ~3 stars, last push 2022): balance check, cash-out, and recharge over plain USSD — works on any feature phone with no internet or data plan. Small and low-maturity, but a genuinely useful low-tech, low-connectivity reference for an offline mobile-money front end; Apache-2.0 is permissive for local modification. Cold-climate viable (USSD/feature-phone).
