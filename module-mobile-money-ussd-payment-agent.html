Last-mile mobile-money / USSD / SMS payment and agent rail: the collection and disbursement front door for prepaid metering, VSLA and remittance, with agent onboarding and commission, offline queue and idempotent reconciliation, micro-denomination and fee transparency, and an offline USSD/SMS fallback. The one genuine cross-cutting gap no existing module fills.
