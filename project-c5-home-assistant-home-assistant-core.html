Open-source home automation platform (Apache-2.0, 91,261 stars, pushed 2026-10-05) that integrates temperature/humidity sensors, thermostats, HVAC climate entities and weather feeds for local, privacy-first climate control — the control layer for a DIY thermal-comfort setup.
