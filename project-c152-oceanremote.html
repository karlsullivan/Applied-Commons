This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Free, open-source low-code IoT platform for ESP32, ESP8266 and Pico W (sensor monitoring, device control, dashboard, no monthly fees). Not cold-chain-specific, but a ready open-source layer that can add the continuous temperature recording + alarm monitoring the brief's health requirement needs on top of any fridge or cold room, running from a small local PV array + battery.
