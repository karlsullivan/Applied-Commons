Open hydrodynamic and land-process model suite (Delft3D-FM and Delft3D4 kernels) for storm surge, waves, sediment transport and 3D water flow - a workhorse for coastal adaptation and defence design. Public code on GitHub under Deltares' open source license (a custom license, not an SPDX identifier). 75 stars, very active (pushed 2026-11-12).
