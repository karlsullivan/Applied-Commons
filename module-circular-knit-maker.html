This is a draft module. It has not been built or tested.

Open-hardware circular knitting machine that knits continuous tube garments (hats, tubes, leg-warmers) with a NEMA23-driven needle drum. A self-contained, mostly 3D-printable + laser-cut machine for continuous-tube clothing, demonstrated at scale (5 machines knitting an art-centre ceiling for 8 months).
