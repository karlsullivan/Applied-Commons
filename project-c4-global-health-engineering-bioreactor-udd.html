This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Public GitHub repo (MATLAB analysis + Arduino control + temperature/energy datasets, 67 files) for a Controlled Heating and Aeration Module to maintain thermophilic composting (50-70C) in multichamber urine-diverting dry toilets — a cold-climate enabler that keeps the chamber hot where ambient is cold. Young (created 2026), no license declared, thermal module rather than a complete toilet.
