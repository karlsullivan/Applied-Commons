This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-hardware (CERN-OHL-S-2.0) bolt-together cargo tricycle: ~37 laser/waterjet-cut 3 mm flat-steel plates, tab-and-slot, ~97 M8 bolts, no welding; standard bicycle parts; ships flat. Rated ~148 kg cargo / 71.7 kg empty; pedal-only prototype ~US$728 in parts (production cost target ~US$300); TRL 3. README lists last-mile parcel/grocery, water and gas-cylinder, and recycling delivery, and notes a vendor 'in Pune or Nairobi can repair one plate at a time.' Pedal-powered and made of commodity parts, so it works year-round in cold climates (no battery/fuel); strong offline, thin-parts and local-maintenance fit.
