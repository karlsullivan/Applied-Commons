Open flatbed-knit machine controller (AYAB)
Kindmixed
Maturitydocumented
NeedsClothing and bodily protection
This is a draft module. It has not been built or tested.

Computer-controlled flatbed knitting: software (desktop + firmware) that drives a used Brother KH-9xx flatbed machine + Arduino + AYAB shield from a pattern file, turning a digital design file into knitted fabric. Removes skilled hand-knit labour and the need for a closed commercial machine. Offline-capable, USB-powered, pattern-only (no automatic shaping).
