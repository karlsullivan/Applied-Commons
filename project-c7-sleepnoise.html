This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source shell project (~43 stars, created 2017, active 2026) that turns a Raspberry Pi or any Linux box with alsa-utils into a scheduled white/pink/brown noise generator to aid falling asleep. Low-cost, locally buildable hardware+software; helps anyone wanting an open, self-hosted white-noise machine.
