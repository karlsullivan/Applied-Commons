This is a draft module. It has not been built or tested.

OpenWrt-based WiFi mesh node and router that rural/isolated communities build and maintain themselves, providing last-mile IP backhaul and a local hotspot; carries the traffic for the SMS/health/market platforms and LoRa gateways where no commercial backhaul exists. Works with or without internet.
