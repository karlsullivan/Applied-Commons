This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

A more finished ESP32-S3 air-quality station: Waveshare 4.3in/7in touchscreens, Sensirion sensors, LVGL UI, local web dashboard, OTA updates, MQTT/Home Assistant and optional 0-10V ventilation control. 3D-printable enclosure and browser flash installer; no cloud required. GPLv3, actively maintained (~765 stars, last push 2026-09).
