AllFreeSewing Homemade Muckluks

NeedClothing and bodily protection
StatusScreened
LicenceNone found
Climatescold, polar
This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Free, extensive sewing pattern and tutorial for handmade leather mukluks (traditional insulated winter footwear) using basic sewing techniques. Helps cold-climate makers who want to build wool/leather insulated footwear by hand. Maturity: free and published tutorial on a well-known pattern site; described as an extensive (not quick) build.

References

  1. Mukluks for Christmas by Mandzal - Instructables tutorial: full materials (veg-tan cowhide sole, scrap cowhide tongue, deerhide leg, canvas, tanner's cement, waxed thread, brass grommets, beeswax), 6-step construction, sizing from insoles +1 inch, failure notes (rigid sole, snow gaps, wet sewing tip), Sew Warm 2013 runner-up; accessed via Wayback snapshot 2020-01-11, live page 404 instructables.com
  2. Mukluks for Christmas - all-steps/printable variant (the exact URL the AllFreeSewing 'Click Here for Sewing Pattern' link targets) instructables.com
