This is a draft module. It has not been built or tested.

Shared, locally serviceable grid-free power block for small field electronics (sensors, controllers, small pumps): MPPT solar charging + 1S Li-ion with BMS + 5 V USB-C and 12 V DC output. Sized by the load's average current so the same block powers many devices. Serves the lighting/safety requirement (R6) and provides base power for field-deployed sensors and controllers across all scenarios. Reuses the existing corpus code offgrid-solar-power.
