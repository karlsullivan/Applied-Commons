This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

The world's first open-source Emergency Warning System dissemination platform (MIT, DPG-certified). Actively used by alerting authorities in Cambodia (NCDM) and Laos (DMH); disseminates life-saving alerts across messages, IVR and Cell Broadcast to basic phones, fully localizable to any language including non-Latin scripts (Khmer, Lao). Directly serves the safety/life multi-channel + local-language + last-mile requirement and is extensible to new hazard types. Mature and documented (open-ews.org, Docker deploy, Terraform).
