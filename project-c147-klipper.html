This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Free, open-source 3D-printer firmware (C, GPL-3.0, ~12,000 GitHub stars, active) that pairs a micro-controller with a cheap general-purpose computer to run a 3D printer. Together with an open RepRap-style printer it is the local-fabrication tool that 3D-prints replacement spares (handles, brackets, pump caps, fittings) on demand instead of waiting on a supplier. Cold-climate fit: 3D printing of spares is indoor, weather-independent work, so it works year-round in long-freezing, low-winter-sun regions, fabricating the parts that keep water/farm/energy equipment running during months when outdoor repair and supply chains are shut down.
