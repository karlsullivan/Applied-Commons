OneCommunity Global — Vermiculture Eco-Toilet
NeedSanitation and hygiene
StatusScreened
LicenceNone found
Climatestropical, temperate
This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source (part of the Earthbag Village project) 100% worm-composting solid-waste toilet with a toilet-and-septic-tank option. Pre-construction: authors state it is not a complete, usable tutorial until they finish their own build — weak maturity for direct build. US (Florida), not cold-climate.
