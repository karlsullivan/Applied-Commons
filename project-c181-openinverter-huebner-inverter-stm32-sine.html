This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Long-running open-source inverter-control firmware (founded 2008 by Johannes Huebner; GPL-3.0 stm32-sine firmware, 200+ stars, active 2026) that drives production EV/motor and grid-tied inverters, repurposed for pump, motor and microgrid/off-grid power control. Directly addresses the open grid/motor inverter-control and pump-actuation requirement with open code and a large community; documentation emphasizes user risk for high-voltage use.
