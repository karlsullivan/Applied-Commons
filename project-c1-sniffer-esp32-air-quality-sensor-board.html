Sniffer (ESP32 air-quality sensor board)
NeedAir and breathing
StatusScreened
LicenceOther
Sourcegithub.com
Last updated upstreamJuly 2026
This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

A KiCad-designed ESP32 integration board (TTGO T-Display + PMSA003 particulate + BME680 environmental) for home AQI tracking; released Gerbers with direct PCB ordering, ESPHome configuration and a documented build; the author reports it tracks within 1% of local PurpleAir sensors. CC-BY-SA-4.0, maintained (~165 stars, last push 2026-07).
