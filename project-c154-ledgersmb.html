This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source web-based double-entry accounting & ERP (570 stars / 172 forks, forked from SQL-Ledger in 2006, stable 1.13). Multi-currency general ledger, receivables/payables, fixed assets, 45 languages, designed to avoid vendor lock-in and to work from a single server. Deployments documented in Canada, Norway, Denmark and Estonia, satisfying the year-round cold-climate requirement with a named, real-world example. Fits cooperative/microfinance general-ledger accounting readable in the local language. Caveat: not a native offline one-device tool; assumes a small server.
