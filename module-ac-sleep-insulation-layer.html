This is a draft module. It has not been built or tested.

Locally-buildable, passive thermal insulation layer (reflective blanket / fleece in a light frame, or a quilted curtain panel) that holds a sleeping area inside the 18-26 C comfort band without powered heating or cooling, using local insulation, fabric and a simple frame assembled with hand tools. Passive and fully open; the achieved temperature is confirmed with an ac-thermal-logger reading.
