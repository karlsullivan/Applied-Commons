This project is discovered: Applied Commons has catalogued it but has not written a build pack for it.

Raspberry Pi temperature + humidity monitoring and control app for wine/beer/meat cellars, kegerators and refrigerators, with graphical logging and out-of-range alarm emails/SMS - the monitor+control layer that keeps a passive cool store in range year-round. Mature app (2015, Pi B/2/3) but stagnant (last push 2019, ~30 stars, no declared license), so treat as referenceable but not maintained. Cold-climate: its target stores (root/wine/meat cellars) are the classic year-round passive cold-climate storage idiom.
