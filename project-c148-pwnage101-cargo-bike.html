This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Fully parametric, upcycled 'long-john' cargo bike design on GitHub: a FreeCAD (.fcstd) parametric design that attaches to any existing traditional bicycle frame and fork, with surrounding automation scripts (Python/shell, dockerfiles, makefiles). Because it reuses an existing bicycle's frame, fork and components, it is a cheap, repairable, locally buildable goods carrier that beats the walking/head-load baseline on cost-per-km. Maturity: hobbyist/individual project, dormant (created 2017, last pushed 2019, 4 stars), so documentation and community support are limited.
