This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Free, open-source parametric 3D modeler (Windows/macOS/Linux) with FEA and CAM/CNC workbenches that produces production drawings; lets local operators design replacement parts, pipe fittings, farm and building components and machine them on the open machines below. Mature and heavily used (~35,600 GitHub stars, LGPL-2.1, active); a learning curve exists but it is well documented and free, with no vendor lock-in.
