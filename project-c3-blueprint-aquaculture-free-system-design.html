Blueprint Aquaculture - free system design tools
NeedFood and nutrition
StatusDiscovered
LicenceNone found
This project is discovered: Applied Commons has catalogued it but has not written a build pack for it.

Free, no-signup aquaponics sizing and cost toolset: a system designer that sizes pumps, biofilters and grow beds, plus calculators for Hazen-Williams pipe friction loss, electrical load, ammonia production rates (per Timmons & Ebeling, 2013), biofilter media (per Rakocy, 2006), and a system cost estimator with bill of materials. Useful for translating a design concept into a sized, costed, locally-sourceable build. Maturity: free commercial-grade tools (public, no account).
