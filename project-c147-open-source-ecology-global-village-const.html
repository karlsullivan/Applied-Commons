Open Source Ecology - Global Village Construction Set (GVCS)

Open Source Ecology - Global Village Construction Set (GVCS)
NeedFabrication and tools
ServesShelter and thermal comfort, Food and nutrition, Water, Continuity of essential services, Economic and livelihood security
StatusScreened
LicenceNone found
Climatestropical, arid, temperate, cold
This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source, freely licensed blueprints/CAD/BOM/build instructions for ~10 industrial machines (including a CMX concrete/brick printer for shelter, a grain mill for food processing, and metalworking lathes/CNC for making and repairing spare parts). A 501(c)(3) nonprofit (Maysville, MO) whose designs are built and replicated worldwide; mature and well documented in its Plans index. Directly addresses the need brief: locally buildable fabrication for shelter materials and repair of water/food/energy equipment by trained non-specialists, using locally procurable inputs. Cold-climate workable: the machines are indoor workshop tools that operate year-round through freezing winters. Not in already_known.
