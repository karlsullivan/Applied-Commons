This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

An open-source QGIS plugin for planning and sizing sanitary sewer-collection networks (condominial systems), developed for the IDB / AECID / LAIF with educational, free-access goals. Provides pre-configured vector layers, hydraulic sizing per Brazilian NBR 9649 (adjustable), SWMM export and tutorials/courses. The most mature, well-documented item here (software, en/pt/es), supporting safe handling of human waste at infrastructure scale.
