Open Source Ecology - Global Village Construction Set (GVCS) and Compressed Earth Brick (CEB) Press
NeedMaterials and circularity
StatusDiscovered
LicenceNone found
This project is discovered: Applied Commons has catalogued it but has not written a build pack for it.

Open-source, libre platform of ~50 industrial machines with all designs shared online for free; the CEB Press turns onsite soil into compressed earth blocks at up to 10 bricks/min, cutting cement/steel and long-distance transport. Helps rural/remote communities self-build low-carbon structures. Mature: first machine built 2007, one-day production time achieved 2012, used to build the 'Microhouse' (2013); ~1/3 of machines at full documented completion as of 2018.
