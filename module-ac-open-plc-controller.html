NeedsInstrumentation and control

This is a draft module. It has not been built or tested.

Open industrial programmable-logic controller (IEC 61131-3 Structured Text compiled to C) running on commodity / embedded hardware for deterministic control of pumps, valves and treatment-plant sequencing in small-farm / community-facility automation, replacing proprietary PLCs.
