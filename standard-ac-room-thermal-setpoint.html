Room thermal setpoint and comfort band
Codeac-room-thermal-setpoint
Kindthermal
StatusApproved
ApprovedOctober 2026
Used by4 modules

Shared by the room climate controller, the home climate hub and the weather-station node. The three visible approved standards (ac-clean-cooking, ac-cold-chain-temperature, ac-food-water-contact-materials) do not cover an indoor comfort setpoint, so this is proposed. Local and free; no per-device cost.

Specification

Indoor target-temperature setpoint in C within a comfort band (default 18-26 C per the domain need brief), plus measured room temperature, control state (heat/cool/idle/fan) and a 0.5 C default hysteresis deadband. Carried as one timestamped JSON object on a local telemetry bus; no cloud dependency.

Used by

  • DIY local weather-station node (Arduino + Android)
  • Local home climate automation hub (Home Assistant)
  • Local room climate controller (ESP32 thermostat)
  • Open building energy & daylight design toolkit (OpenStudio + EnergyPlus)
