This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Cross-platform, open-source desktop (and, via companion apps, mobile) GIS engine: view, edit, analyze and print vector/raster/mesh/point-cloud data in dozens of formats and consume WMS/WFS web services; integrates GDAL, PostGIS, GRASS, SAGA and MapServer and a large Python/C++ plugin ecosystem. This is the de-facto open standard and the general-purpose engine that hosts the other candidates (InaSAFE is a QGIS plugin; Mergin syncs QGIS projects). Who it helps: governments, NGOs, researchers and local GIS staff needing a free, locally-owned mapping/analysis platform instead of proprietary GIS. Maturity: in development since 2002, current stable 4.2.3, GPL-2.0+, ~14.8k GitHub stars, very high activity (pushed on the retrieval date). General-purpose (not cold-climate-specific), but fully offline-capable.
