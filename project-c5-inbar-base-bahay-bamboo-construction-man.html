INBAR / Base Bahay - Bamboo Construction Manual for Single-Story Housing

INBAR / Base Bahay - Bamboo Construction Manual for Single-Story Housing
NeedShelter and thermal comfort
StatusScreened

Climatestropical, temperate
This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-access illustrated manual (released 5 November 2025) for building a single-story bamboo house using the Composite Bamboo Shear Wall (CBSW) system: step-by-step from treating and structurally grading bamboo culms to prefabricating wall panels and roof trusses, with parallel site-preparation and foundation work for rapid on-site installation. Targets lower- and middle-income countries with abundant bamboo; aims at resilient, comfortable, low-carbon, earthquake- and typhoon-resistant housing from local materials.
