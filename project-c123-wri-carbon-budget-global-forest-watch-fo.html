This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source (GPL-3.0, 88 stars) Python framework that maps gross forest GHG emissions, gross carbon removals (sequestration) and net flux at 30 m resolution, 2001-2025, across all carbon pools; feeds the Global Forest Watch platform. Provides the open, auditable MRV layer for biological CDR at scale. Global coverage including boreal forest, so usable for carbon accounting in cold climates.

References
