This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-hardware air purifier using standard MERV 13 HVAC filters and off-the-shelf PC fans, with laser-cut (DXF) enclosure files and a parametric web builder; targets lower cost of ownership per m3 CADR than commercial purifiers and easy repair. GPL-3.0 (~410 stars, 2024).
