This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source (MIT) design for a solar-powered NH3-H2O absorption refrigerator for off-grid use (stated target: Sudan and similar climates): a 200 W / 150 L cold box held at 2-8 C, ~0.42 COP, CPC solar collector, with public CAD (OpenSCAD) and a P&ID plus a CoolProp/teqp thermodynamic model. It addresses the brief's off-grid mechanical-cooling requirement and the 2-8 C health band, and NH3 is a zero-GWP working fluid (meeting the low-GWP refrigerant requirement). Honest caveat: it is research-stage and explicitly 'not for fabrication' (unresolved pressure, material, geometry and safety issues) -- a public design path, not yet a mass-buildable unit.
