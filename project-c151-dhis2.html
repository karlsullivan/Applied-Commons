This project is under research: Applied Commons has catalogued it but has not written a build pack for it.

Free, open-source, no-code-required health and development information system (collect, validate, analyze, visualize) hostable in-country and run by ministries of health; used in 80+ LMICs covering ~2.4B people. Core is BSD-3-Clause (dhis2-core), active (pushed 2026-11). Cold-climate capable: the project is a global collaboration led by HISP UiO (University of Oslo, Norway) and is a web-based server platform that runs year-round, including through long Norwegian winters.
