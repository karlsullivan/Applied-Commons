This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open PDF repair manual explicitly written to address 'the shortage of trained pump repair technicians' — the skills side of the hand-pump sustainability problem, complementing the public-domain RWSN pump specs. Maturity: published open manual (Lifewater, updated 2024); paired with the WFPIT India Mark II repair & maintenance manual. Meets the water requirement for a locally buildable technician training / repair-knowledge package for the dominant rural handpump base.
