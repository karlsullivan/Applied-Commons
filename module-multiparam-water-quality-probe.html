This is a draft module. It has not been built or tested.

Locally buildable water-quality sampler/probe measuring the parameters the need-brief's requirements turn on (pH, EC/conductivity, ORP, temperature, dissolved oxygen, and optionally turbidity/TDS) so a community can verify whether its treated water meets the microbial/chemical targets and catch a failing filter; stores to SD card and reads on a phone via Bluetooth, so it works offline.

Variants

  • 5-parameter core (temp, pH, EC, ORP, DO) - the documented KnowFlow parameter set
  • + turbidity/TDS (adds a turbidity or TDS sensor; supports the <=5 NTU / <1 NTU target check)
  • + nitrate test strips (chemical cross-check, non-electronic, for arsenic/fluoride/nitrate spot checks)
