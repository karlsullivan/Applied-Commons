This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source programmable logic controller runtime that emulates a PLC on standard Linux/Docker and embedded hardware; supports IEC 61131-3 and ladder-diagram logic via an IDE, and acts as both a Modbus/TCP server and client. Positioned as a low-cost open industrial automation solution. Provides an open, locally maintainable control layer (Modbus) for pumps, valves, treatment plants and other essential infrastructure, replacing proprietary PLCs.
