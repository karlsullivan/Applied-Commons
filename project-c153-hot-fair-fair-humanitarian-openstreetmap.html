This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

HOT's free, open-source (AGPL-3.0) AI-assisted mapping platform: mappers choose or build computer-vision models, run them over their own imagery/area of interest to detect buildings and other features, review predictions with humans in the loop, and publish open data for humanitarian use — no AI/ML programming skills required. Public service shows 140 published models, 810 registered users, 10,222 accepted predictions; repository active (push 2026-11-19) and HOT is running an open call for Earth Observation GeoAI models. Addresses the scale gap of the ~170,000 unmapped villages by combining volunteer bandwidth with AI extraction.
