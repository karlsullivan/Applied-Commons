This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

JPL-designed, tested 3D-printed respirator to help the pandemic response; public design files (G-code) for 3D printing. For medical and high-risk workers needing filtered-air protection; mature (131 stars, 162 commits, 6 contributors) and documented, low-cost, locally buildable.
