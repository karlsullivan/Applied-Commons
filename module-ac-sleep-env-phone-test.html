Phone-based sleep-environment test

This is a draft module. It has not been built or tested.

Open, self-hosted software that turns an existing phone into a combined sleep-environment tester using its built-in light, microphone and (where present) temperature sensors, ingesting ac-sleep-env-verification records and reporting night noise, blackout and temperature against the need_brief targets. No new hardware required; a low-cost fallback for homes that cannot afford the US$10-20 dedicated meters. Fully open (GPL-3.0-or-later).
