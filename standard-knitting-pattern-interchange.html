ISO 23606:2009 is the ISO symbolic-notation standard for knitted-fabric pattern drafting; the machine semantics are AC extensions, labelled as such. OPAF is an open, versioned pattern spec; AYAB API v6 is the current open machine interface; PNG (ISO/IEC 15948:2004, maintained by W3C) is a universal, free container. Aligns FOSSASIA knitting, AYAB and OpenKnit to one open interchange and adds the missing version/magic header and explicit colour and orientation model.

Specification

A knitting pattern interchange document is a structured pattern file (Open Pattern Format style) whose required root element carries a name, a Semantic-Versioning version and a unique_id (a UUID per RFC 9562, which obsoletes RFC 4122; aligned with ISO/IEC 9834-8). A header magic string plus version field is mandatory and must be parsed before any stitch executes. Notation: human-readable charts use the symbolic notation of ISO 23606:2009 (pattern-draft grids, symbols and auxiliary signs). AC extensions beyond ISO 23606, which defines no machine semantics: the machine action vocabulary (knit, tuck, hold, lift, transfer), orientation and repeat semantics, the colour array, and the instruction-stream canonical form. Canonical form: an instruction-based, non-grid sequence of stitches (the source project's model, where the work is a linear instruction stream that can split the work - e.g. two legs - without a rectangular frame). The row x column grid is a machine-executable projection: a required mapping section documents the grid<->instruction transform, where a contiguous rectangular region of the stream is compiled to a grid for one machine pass, and non-contiguous or split regions are emitted as separate grid sheets keyed by a region id, so the grid never silently re-merges split work and the stream round-trips without loss. Machine output for flatbed (AYAB): the current AYAB interface (API v6, firmware 1.0) - a PNG pattern image (up to 200 px wide, 1-bit, one pixel per stitch) from which the host sends row-by-row binary pixel data over serial with CRC8; the pre-1.0 '.g' format is not used. Container: PNG (ISO/IEC 15948:2004; the maintained specification is the W3C PNG Third Edition Recommendation, 2025, not yet an International Standard), carrying the machine raster as the image and the human-readable pattern in ancillary/private chunks. Colours: sRGB RGB triples (#RRGGBB) per IEC 61966-2-1:1999; any named-colour vocabulary (e.g. OPAF's named colours) is defined separately.
