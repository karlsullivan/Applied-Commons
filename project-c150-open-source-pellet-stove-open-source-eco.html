This project is discovered: Applied Commons has catalogued it but has not written a build pack for it.

Public open-hardware design for a biomass pellet stove (fuel storage, auger, hearth, ash handling, control modules) from Open Source Ecology's construction set; locally buildable biomass heating with documented design rationale; early-maturity design, well documented on the OSE wiki; cold-climate relevant as heat source.
