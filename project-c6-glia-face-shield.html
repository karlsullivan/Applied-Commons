Low-cost reusable face shield (3D-printed headpiece + Mylar sheet + elastic strap) currently in use in London, Canada, the West Bank and Gaza; full bill of materials, print and decontamination instructions under TAPR OHL/GPLv3. For frontline and medical staff; mature and real-world deployed.

Evidence

The strongest findings from Applied Commons research on this project:

  • The 3MF the README instructs users to import is absent from the repo's default (master) branch. master's full tree contains only source/stl/headpiece.stl, source/cad/headpiece.FCStd (Fusion360), facesheet-{large,small}.svg, an instructions image, README.md, DECONTAMINATION.md, and LICENSE — no .3MF anywhere. The premise of the question is confirmed.
  • The README print instructions are self-contradictory: they state both 'Modify filament and printer settings as needed' and, on the immediately following line, 'DO NOT MODIFY PRINT SETTINGS', while also telling users to 'import 3MF file' in PrusaSlicer 2.2+ — a 3MF that master does not ship. The same contradictory text appears verbatim in the freecad-branch README.
  • The design under test is a reusable 3D-printed (PETG/ABS) closed headband with a buckle plus a thin 0.254 mm clear Mylar (PET) sheet and elastic; the frame is disinfected by a 1-minute warm bleach soak. Approximately 10,000 units were produced in Canada in 2020 and the project was closed December 2022. This matters because the protective element is a cheap disposable mylar sheet, while the UV/fog/scratch-degradation risk concentrates in that sheet.
  • The discrepancy is already a known, reported bug: open issue #35, titled '[BUG] 3MF file missing from default Branch'.
  • No verified soak/wear cycle count to crack propagation or clouding exists in the public record for the 0.254 mm Mylar (PET) sheet or the PETG headpiece under Glia's bleach decon. The Glia team stated explicitly (issue #14): 'We have not done long term testing... We don't have data right now in how many cleaning cycles a typical mask will tolerate.'
  • No numeric replacement interval is defined for the sheet. The replacement rule is visual: 'The mylar will get scratched and cloudy over time, at which point it will need to be replaced (just the mylar screen).' A dedicated replacement Mylar sheet part was made so only the sheet (not the whole shield) is swapped.
  • Official decontamination protocol (GliaX/faceshield README): disassemble headpiece from strap and Mylar sheet; soak entire shield and strap 1 minute in warm bleach solution (well-ventilated area); rinse with water; hang to dry. Public face-shield docs do NOT state a bleach concentration/ppm.
  • A 3MF already exists in the repo on the freecad branch (faceshieldx1.3mf, ~855 KB), and an open, unmerged pull request (#36, opened 2023-01-01, still unmerged) — co-authored with Glia founder Tarek Loubani and designer Jacob Bender — adds it to master. Its description states it 'Would resolve #35 if merged.' So 'should a validated 3MF be added?' is already answered in-repo as yes, and the change is proposed but simply never merged.
