This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Low-cost, open-source device to measure water turbidity (a key drinking-water quality indicator), aimed at communities in developing countries that cannot afford lab/equipment analysis. Open hardware (Eagle schematics), Arduino/C/C++ firmware, NTU-based measurement. Early-maturity/research stage (created 2013, ~19 stars). Covers the water/safety sensing requirement.
