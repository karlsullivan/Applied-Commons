This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source modular DIY desktop lathe (3D-printed/concrete body, NEMA23, 15mm linear rails, 12mm ball screws, 125mm chuck, MT5 spindle) for turning metal, wood and plastic parts. Provides an open, locally buildable precision-machining capability for making shafts, fittings and repair spares; documented on GitHub/Thingiverse with an active design iteration. Cold-climate workable (indoor). Not in already_known.
