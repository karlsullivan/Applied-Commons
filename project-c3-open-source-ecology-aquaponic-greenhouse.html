This project is discovered: Applied Commons has catalogued it but has not written a build pack for it.

Open-source 832 sq ft aquaponic greenhouse built Fall 2015 at Factor e Farm (Maysville, Missouri, cold winters): 2 in-ground fish ponds, 44 6-ft aquaponic towers, 216 ft troughs, 2 compost beds, chicken coop, passive-solar + in-ground hydronic heating. Public sweetHome3D CAD, part library, 3D CAD page, and 2015/2016 + 2021 workshop docs ('design your own version larger or smaller'). Mature, built, fully open designs.
