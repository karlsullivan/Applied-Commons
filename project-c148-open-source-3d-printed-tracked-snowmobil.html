This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Closest genuinely open cold-climate tracked vehicle found: a fully open-source 3D-printable tracked snowmobile using Open RC F1 electronics (Printables model 50924), plus a public Thingiverse remix (thing:7296197) that scaled the center frame to carry Ardupilot autopilot and a larger 4250 560KV motor. Honest caveats: RC/toy scale rather than an adult cargo carrier, small community, files on maker platforms rather than a maintained repository - it demonstrates the open, locally-printable tracked-on-snow approach, not a finished year-round workhorse.
