This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Global open community LoRaWAN network powered by the open-source The Things Stack: 153 countries, 21.2K gateways, 297K members, with open-source gateway hardware and a low-power, long-range radio model suited to remote and cold-region deployments (e.g., weather and hazard monitoring). Very mature and globally deployed; serves as an open-source sensing/backhaul backbone that can feed early-warning and market/health data to communities where commercial cellular is absent.
