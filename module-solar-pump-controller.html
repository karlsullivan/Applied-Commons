This is a draft module. It has not been built or tested.

Solar + battery controller that runs a DC pump (or a small inverter for an AC pump) from a PV string where no grid exists; the off-grid power path that lifts water and, optionally, feeds a powered disinfection stage or the storage telemetry node.
