This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source (MIT) smart hydroponics system that continuously monitors the growing environment and automates conditions, built to be extensible and community-driven, with firmware in C/Rust and a docs site. Adds a software-defined automation angle on top of open structures. Maturity: early and fresh - repository created April 2026, 1 star and 11 open issues, so promising but not yet a proven, widely-replicated build; include as a forward-looking automation option rather than a turnkey design.
