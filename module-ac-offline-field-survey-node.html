This is a draft module. It has not been built or tested.

Android-phone + local-broker node that runs ODK Collect and/or Kobo Collect against a local server for offline form capture (household, WASH, food-security, climate-vulnerability surveys) with batch sync over mesh/LoRa when connectivity returns. Extends the existing ac-odk-offline-collection-station with Kobo/Enketo form compatibility.
