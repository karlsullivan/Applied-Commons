This project is discovered: Applied Commons has catalogued it but has not written a build pack for it.

A simple patronage-point system for networked cooperatives (GPL-3.0, created 2026, very small). Fills the specific cooperative dividend/patronage-allocation function that general double-entry tools such as Beancount do not provide out of the box — directly addressing the 'savings-group/cooperative accounting (patronage, member statements, loan cycles) is not first-class' gap. Young and small; cold-climate viable (software).
