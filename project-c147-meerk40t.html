This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

MIT-licensed open-source laser cutting and engraving control software for widely available K40 / GRBL / fibre lasers, letting a locally assembled or purchased laser cut and join building and tooling materials using openly licensed software instead of vendor-locked controllers. Runs on Windows, macOS, Linux and Raspberry Pi. Mature with active 0.9.x releases (currently in community-driven maintenance mode).
