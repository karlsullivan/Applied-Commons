This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source, human-powered (optionally electric-assisted) three-wheeled cargo bike documented using Open Know-How standards, explicitly designed for urban and rural transport of goods, sustainable logistics and low-cost local manufacturing, with all files released under open-source licenses to support community replication. It is the closest single candidate to the brief's 'open, locally buildable, cheap last-mile carrier that matches the informal baseline on cost-per-km' requirement. Maturity: design-stage - the GitHub repo was created in May 2025, has minimal traction (1 star, 0 forks) and the primary fetch was served only via GitHub metadata, so build documentation depth is unproven.
