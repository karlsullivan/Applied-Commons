This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Full open-source ERP (GPL-3.0) from Frappe, one of the largest projects on GitHub (~41,000 stars, active), including a complete double-entry accounting module, point-of-sale, payments, and inventory, deployable entirely on-premise. For this brief it is the cooperative/community accounting and food-credit enabler: a rural cooperative or agri-SME can run double-entry books, issue to-harvest credit and record mobile-money repayment, all on hardware it owns, in local language via configurable fields. Very mature and widely documented, though heavier to deploy than a purpose-built tool, and savings-group/patronage accounting is a module to configure rather than first-class.
