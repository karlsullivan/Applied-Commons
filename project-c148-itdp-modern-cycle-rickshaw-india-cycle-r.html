This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Public AutoCAD design package for the modernized cycle rickshaw of the India Cycle Rickshaw Improvement Project: integral tubular frame (30% weight reduction), multi-gear system designed specifically for rickshaws, lower center of gravity for stability - from a project that put nearly half a million rickshaws on roads in North India (per the ITDP page, retrieved). AutoCAD .zip download link on the page. The strongest open low-cost passenger/cargo three-wheeler design found; human-powered (no motor), fits the 50-100 kg payload plus rider and 50-km-parts-radius constraint.
