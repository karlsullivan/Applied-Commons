This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source hydroponics automation: a RootMaster controller board plus the hypo CLI for monitoring and controlling nutrient/hydroponic systems over a Raspberry Pi. Helps home growers and small growers automate soilless production. Maturity: high - active project, RootMaster rev 3 boards built and shipped, blog and docs through 2025.
