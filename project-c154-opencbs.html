This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source core banking system (GPL-3.0, 110 stars, maintained since 2017) explicitly built for Microfinance Institutions, Cooperative Financial Institutions, digital lenders and mid-size banks. Client, loan, savings, collateral management plus accounting and reporting, designed to deploy in weeks. Mature and documented. Complements Fineract for cooperative/savings institutions doing food to-harvest credit and group lending. Caveat: heavier server-oriented ERP; not itself an offline one-device tool.
