This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source hydraulic compressed-earth-block press that presses local soil into 4x6x12-inch plain building blocks at about 6 blocks/minute, using no cement, with a US$3,000-6,500 bill of materials (1,700 lb machine, adjustable 2-4 inch brick height). It is a low-embodied-carbon, locally-sourced shelter material for anyone who can source local earth, part of the long-running Global Village Construction Set (Open Source Ecology, founded 2003; this is press version 17.08). Open hardware under CC-BY-SA 4.0 with an open controller and software under GPLv3 (per the repo README). Because it dry-presses local earth - no cement, no mixing water, no curing - it is suitable for regions with long freezing winters, unlike cement/concrete which need curing protection. Cost to replicate is documented in the README (material cost plus optional manual variant).
