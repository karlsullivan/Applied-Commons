This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source CNC control software (GPL-3.0) from the OpenBuilds project, part of a community of open, low-cost CNC machine designs, controllers and post-processors. Gives local builders and repair shops an open, self-hostable control stack to run, repair and modify a milling machine or similar workshop machine.
