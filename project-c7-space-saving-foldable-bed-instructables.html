Space Saving Foldable Bed (Instructables)
NeedSleep and rest
StatusDiscovered
LicenceNone found
This project is discovered: Applied Commons has catalogued it but has not written a build pack for it.

Open fold-down/murphy-style bed (CC BY-NC-SA 4.0) that stows the sleep surface when not in use to free a small room. Helps sleepers in small shared dwellings (space driver); passive, no power. Mature: published 2019, featured, ~16K views, with build steps and a video. Note: the design uses a metal frame and the build thread mentions welding, so it suits a semi-skilled maker with metalworking access rather than a purely hand-tool build.
