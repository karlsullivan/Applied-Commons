This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source (MIT) non-custodial rotating-savings ('susu'/savings-group) protocol and applications built on Stellar's Soroban smart contracts, with public web client and contracts (27 stars / 60 forks, active 2026). Fits the savings-group requirement by giving groups programmable, transparent, member-held savings and rotating credit instead of a paper ledger. Caveat: online (depends on the Stellar network), not offline-first; young project.
