This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

European Commission JRC open-source hydrological flood model (EUPL-1.2, 172 stars, actively maintained) that powers Europe's flood forecasting (EFAS / Copernicus) and supports cold-climate European catchments. Provides the modelling/detection layer for water-hazard early warning (floods, and adaptable to glacial-lake outburst floods), feeding alert systems like OpenEWS. Cold-climate fit (long-freezing-winter European basins).
