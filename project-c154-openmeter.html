This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source (Apache-2.0) usage-based metering-to-billing engine (openmeter.io, active, ~2,400 stars) that ingests usage events, applies pricing models, and produces invoices and receivables; deployable on-prem with Postgres/ClickHouse. For this brief it is the PAYGo/instalment-billing and receivables layer: it turns metered consumption (from OpenEMS/emoncms) into small micro-denomination invoices and tracks receivables so debt, not only equity, can underwrite solar-home-system and input financing. Honest caveat: it is oriented to self-hosted/enterprise metering and is cloud-leaning, so it is best paired with an offline meter for true no-connection operation, and it does not itself handle micro-denomination cash agents.
