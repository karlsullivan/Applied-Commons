This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source desktop CNC milling machine (Milo V2.0) published under open-source values, designed to be built without special tools or expertise, fitting a desktop or garage. Low-cost, locally buildable, and directly usable for machining spare parts and small components for water/energy/agricultural equipment by a trained non-specialist. Cold-climate workable (indoor machine). Not in already_known.
