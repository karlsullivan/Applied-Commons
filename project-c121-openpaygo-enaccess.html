This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source Pay-As-You-Go token protocol plus hardware examples (Apache-2.0) that lets any off-grid manufacturer add secure, remotely-activated device control via a token; token generation can plug into PaygOps or another billing platform and the validator drops into virtually any device, directly addressing the 'households can't afford upfront connection fees / pay-as-you-go is required' financing constraint. Mature: maintained by EnAccess with full documentation covering keypad, GSM/3G, WiFi and LoRaWAN variants plus a documented design-choice guide.
