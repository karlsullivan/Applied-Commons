This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Privacy-first, open-source offline maps and GPS navigation app (Android/iOS) on OpenStreetMap, designed to function without internet: download maps, then search, plan routes, record tracks, navigate and even edit OSM offline, with no ads or user tracking; includes offline elevation data. COLD-CLIMATE (works year-round in cold regions): explicitly built for offline/remote use (remote trails, travel without a data connection) with an offline OSM editor, so it functions in freezing, low-sun, no-network conditions. Who it helps: travelers, hikers, drivers and remote/rural and humanitarian users needing dependable offline maps. Maturity: fork of Maps.me (2020), Apache-2.0, active (2026), 12M+ installs.
