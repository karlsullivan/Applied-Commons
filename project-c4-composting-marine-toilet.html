This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

A documented build for a urine-diverting composting toilet the height of a standard Jabsco Type III, replacing a boat's OEM unit. Uses off-the-shelf parts (2-gallon paint bucket, bleach bottle, plywood enclosure) plus a 3D-printed (5-part) urine diverter. Open, reproducible, low-cost hardware documentation for marine/compact sanitation; early-stage.
