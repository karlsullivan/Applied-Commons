This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source (software and hardware) solar inverter project whose goal is a design buildable from parts available through common distributors with no special manufactured parts; all documentation (software, hardware, mechanics) is open and free. Directly serves the need brief's energy requirement - open, locally buildable assembly and repair of off-grid inverter/charge-controller components so off-grid power stays available. Cold-climate workable (indoor fabrication/repair). Not in already_known (OpenEMS is a different, monitoring project).
