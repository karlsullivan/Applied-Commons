Recycle Rebuild - Open Recycled-Plastic Brick

Recycle Rebuild - Open Recycled-Plastic Brick
NeedMaterials and circularity
StatusDiscovered
LicenceNone found
This project is discovered: Applied Commons has catalogued it but has not written a build pack for it.

Open-source (public release Jan 2020) interlocking recycled-plastic building brick; each brick sequesters 1.5kg of plastic waste, builds like Lego with only a hammer, is hollow for insulation, and is designed for deconstruction and reuse. It is made using Precious Plastic's open-source recycling machines, so it is a distinct brick project (not a duplicate of Precious Plastic itself). Helps low-income/disaster-affected communities build from plastic waste; also proposed for low-cost WASH facilities. Maturity: design publicly released and being built by distributed workspaces, but still early (demo-scale structures, seeking funding for development).
