This is a draft module. It has not been built or tested.

Locally buildable thermal ensemble holding core temperature above 35 C at -10 C for >=4 h at low wind: layered outer + insulation + knit base layers, plus insulated footwear; the thermal-insole variant extends the existing open-insole-pipeline (MIT) from orthopedic correction to thermal insulation.
