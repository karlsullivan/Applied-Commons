This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source Android apps under the LibreHealth incubation group (mhbs) implementing the WHO/Project ECHO Helping Babies Survive program: an mHBS Trainer app (birth-asphyxia resuscitation), an Essential Care for Every Baby app (essential-newborn-care package: danger signs, cord/skin care, early breastfeeding, prophylaxis), an mHBS Tracker app (DHIS2 Data Capture based), and the NeoRoo app for real-time kangaroo mother care metrics. Covers the resuscitation-skill side (operating resuscitation per protocol for trained midwives/CHWs), the essential-newborn-care package, and KMC tracking. Mobile/offline-first and climate-agnostic (usable year-round in cold climates). The accompanying NeoWarm warming device itself is patented, so the open-source contribution is the software, not the device hardware.
