This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source (ISC) extended fork of the iD OpenStreetMap editor maintained by Meta with AI-generated suggestion layers for roads, buildings, sidewalks, address points and trees plus a catalog of authoritative open data to validate, with per-object human review before upload. Provides the AI-assisted, human-in-the-loop building/street extraction needed to close the ~170,000 unmapped-village gap at volunteer scale; multilingual, web-based.
