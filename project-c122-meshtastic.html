This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source, off-grid, decentralized LoRa mesh network running on affordable, low-power devices with no cell towers, WiFi or internet; AES-256 encrypted with several-kilometer range. Very mature (43+ community-supported devices, 776+ code contributors, 26 LoRa regions, 39 languages) with a Python CLI/SDK and web client. Actively organized in cold-climate regions (Arctic/subarctic Canada NWT-YT-NU, northern US/SoDakMesh, Scotland/UK) and is a good last-mile early-warning and off-grid messaging backbone; caveat: end users need a Meshtastic device, so it complements rather than replaces feature-phone SMS for individual recipients.
