This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source (MIT, ~653 stars, active 2026) Android app that reads your own health wearables without a vendor cloud subscription and computes Sleep, Recovery, Strain and more. Helps people who already own a supported wearable but want open, no-subscription sleep/recovery data.
