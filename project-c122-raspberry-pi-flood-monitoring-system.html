This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source (MIT-licensed) Raspberry Pi system for river-level sensing, rainfall monitoring and local alerts to support hydrological observation and flood-risk early warning; provided as a reproducible, documented prototype for engineers, students and researchers (part of the Sustainable Catalyst series). Directly addresses the water/flood early-warning requirement and is extensible to water-related hazards; maturity is prototype/early-stage rather than production-deployed.
