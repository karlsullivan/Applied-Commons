This project is under research: Applied Commons has catalogued it but has not written a build pack for it.

Open-source (GPL-3.0, 962-star kiwix-tools; 20+ years old, 10M+ users in 212+ countries) suite that brings free knowledge (Wikipedia, medical guides, educational videos, repair manuals and custom content) offline via downloadable ZIM files, readable on any low-cost device including a Raspberry Pi or a Wi-Fi hotspot, in 100+ languages. COLD-CLIMATE GROUNDED: the Kiwix site documents a school running entirely on a Kiwix Hotspot in the remote, high-altitude, long-freezing-winter region of Ladakh (India), and users working off-grid ('I work off grid and Kiwix allows me to keep access to my data at all times').

Evidence

The strongest findings from Applied Commons research on this project:

  • Update cadence is per-recipe periodicity enforced by Zimfarm ('it decides when a ZIM file should be recreated, based on the recipe'). Measured from actual build timestamps (last ~10 builds per recipe): Hindi medicine dump median gap ~31d (monthly 2025-03..2025-09, then gap, resumed 2026-05/08); en/fr medicine ~90d (quarterly); de/en/es/fr climatechange ~34-40d (monthly); TED topic sets ~90d (quarterly); canadian-prepper ~90d; usda-2015 static (one build 2025-04-11); zimgit post-disaster only rebuilt on upstream git changes (2021-12..2024-05, now disabled). No weekly/daily rebuilds observed in the pipeline.
  • Locally produced, regularly updated advisory content CAN be published through the catalog via three institutionalised paths: (a) Zimit self-service (zimit.kiwix.org) - anyone can ZIM any website; 285 zimit recipes in the farm, 99 non-English (ar 42, fr 26, fa 6, es 5, ...); (b) openZIM CMS (cms.openzim.org, 'Publishing platform for the Kiwix Catalog') - editor-reviewed books/collections lifecycle, backend ingests Zimfarm notifications into catalog books and serves per-collection catalog.xml for reader discovery; (c) zim-requests (596 open issues) as the intake path for new ZIMs (license must be clarified). 68 zimgit/nautilus recipes already in the catalog (56 non-English: fr 44, ro 9, mr 2, zh 1) prove locally authored, non-Wikimedia content already flows through. Bottleneck for local advisory content is editorial curation + licensed updatable source + monthly/quarterly cadence ceiling, not catalog mechanics.
  • No purpose-built agriculture-advisory ZIM in local languages exists in the live Kiwix pipeline today. Closest matches (from keyword scan of all 3,084 Zimfarm recipes): ted_topic_agriculture / ted_topic_farming / ted_topic_food (multilingual TED talks, last builds 2026-09-08/16/12), Wikipedia 'medicine' topical dumps in ~20 local languages (hi, fa, ja, uk, it, ta, ur, bn, kn, ml, mr, te, pa, etc., last builds 2026-08 to 2026-10), usda-2015_en_all (English, single build 2025-04-11, static), canadian-prepper_en_preppingfood (English YouTube, quarterly), zimgit_en_post-disaster (English, disabled since last build 2024-05-25).
  • The live catalog pipeline is not 'mostly static Wikimedia dumps': across 3,084 recipes mwoffliner (Wikimedia) is only 38.5% (40.3% of the 2,682 enabled); the other 61.5% is self-produced/curated content - TED 11.6%, zimit 9.2%, devdocs 7.9%, maps 6.7%, sotoki 5.9%, youtube 5.9%, phet 3.7%, gutenberg 3.4%, zimgit 2.2%, freecodecamp 1.9%, wikihow/zimwright/mindtouch/ifixit/kolibri the rest - most rebuilt on schedule. (Scoping caveat: this measures the live farm pipeline; the broader static ZIM inventory on download.kiwix.org includes many one-shot historical files.)
  • No dedicated hazard/early-warning ZIM in local languages was found in the pipeline. Closest: wikipedia climatechange topical dumps (de/en/es/fr, rebuilt ~monthly, last 2026-10-13..16), ted_topic_natural-disaster + ted_topic_weather (multilingual video, ~quarterly, last 2026-09-14/16), zimgit_en_post-disaster (English, dormant). Web search found WMO/FAO agricultural early-warning programmes (EW4All, MHEWS, IDMP) are online services - no ZIM distribution from them surfaced.
