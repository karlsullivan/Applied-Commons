This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source (AGPL-3.0) 'logistics operating system' - a modular platform for fleet management, courier/last-mile delivery, e-commerce fulfillment, warehouse operations and accounting, with dispatch, live tracking/telematics, route optimization, proof-of-delivery and healthcare/pharmacy delivery workflows; self-hostable or cloud. It is a genuinely open, actively maintained logistics tool (~4,300 GitHub stars, frequent commits) usable by community/NGO fleets, but it assumes server infrastructure and smartphone clients, so it does not by itself meet the brief's 'works on a basic phone without continuous connectivity' constraint and is best paired with a field data layer such as ODK.
