This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Free software (GPL-3.0, 4,763 stars / 415 forks) plain-text double-entry accounting, continuously improved since 2007. A single cross-platform binary with CLI/TUI/web; human-readable plain-text journal the user controls, offline, idempotent and re-runnable (no cloud, no vendor lock). Fits re-runnable group/savings ledgers that members can read, verify and audit in their own language. Cold-climate capable (pure software, no climate-dependent hardware).
