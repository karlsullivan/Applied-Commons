This is a draft module. It has not been built or tested.

Web tool (BSD-2-Clause, Digital Public Good) that divides a mapped area into assignable mapping tasks with QA/review workflow, showing which areas need mapping - the volunteer-scale orchestration the brief's 'volunteer + AI-assisted' constraint calls for (e.g. campaigns on ~170,000 unmapped villages). Self-hostable; active roadmap (v5, FastAPI, MapLibre, planned AI integration and uMap/MapSwipe hooks). Runs the campaign loop that feeds work to the editing-station and field-collection modules and checks their output.
