This is a draft module. It has not been built or tested.

A DIN-rail-mountable node that reports vehicle position (GNSS), battery state (24 V swap-bay pack), and an attached cold-chain logger, over a LoRaWAN uplink with an offline buffer. Shared across the cargo bike, the OpenEV powertrain and the cold-chain box so Fleetbase can track any vehicle in the village / homestead / small-farm / community-facility scenarios. Grounded in OpenEV (GPL-2.0), whose documented Python/CAN vehicle interface is the programming plane it reads.
