This project is under research: Applied Commons has catalogued it but has not written a build pack for it.

Mobile field-data collection with instant two-way sync to QGIS using open GeoDiff formats: open a QGIS project on a phone/tablet, digitize and edit features in the field, merge changes automatically back to the project, and share/publish by URL; explicitly designed to work offline on mobile. Bridges the last mile between desktop GIS (QGIS) and in-the-field community data entry. Who it helps: GIS teams, NGOs and local surveyors mapping on a phone without specialist staff or always-on bandwidth. Maturity: commercially backed open-source project, GPL-2.0 (mobile client) with open GeoDiff library (MIT), ~394 GitHub stars, active (pushed on the retrieval date).
