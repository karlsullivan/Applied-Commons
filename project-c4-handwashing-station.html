This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Seattle Makers' public handwashing station: open microcontroller code plus a 3D-printed case (SCAD/STL/3MF, parametric Fusion model) with a documented assembly. Open hardware+software for hand hygiene in public facilities; documented, low-cost, locally printable; early/mid-stage.
