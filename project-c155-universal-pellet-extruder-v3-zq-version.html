An open-source (GPLv3) 3D-printed rework of Mahor's pellet extruder v3 that converts shredded waste plastic into uniform pellets (suitable for re-extrusion or 3D printing). It is a 3D-printed add-on that mounts directly to a CR-10 3D printer, and specifically fixes the original design's wobble/flexibility, dust-and-mess from active cooling, and shredded-plastic blockage/friction issues (per the repo description). The repo includes the full open design - FreeCAD source (.FCStd files), STLs, photos and a README - under GPLv3 (36 stars, 12 forks, last push Jan 2019). It is low-cost and locally buildable by anyone with a CR-10-class 3D printer, and serves local plastic recycling by upcycling waste plastic into reusable pellet feedstock. Indoor operation, so cold-climate capable. Note: the dependency on an existing 3D printer is a real (but modest) prerequisite, and the project is moderately mature.
