This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source weather forecast API that stitches high-resolution model output from many national weather services (DWD, NOAA, Meteo-France, ECMWF, UK Met, JMA, etc.) into a seamless, no-API-key, free-for-non-commercial JSON API with historical, ensemble, seasonal, air-quality and flood endpoints; open under AGPL-3.0 (code) with CC-BY 4.0 (data). Actively maintained (pushed 2026-11, 6.6k stars). Provides open weather/climate data infrastructure useful for health, agriculture and early-warning use cases, and the code is self-hostable.
