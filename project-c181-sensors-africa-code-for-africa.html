This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Citizen-science air-quality network (GPL-3.0, active 2026) providing low-cost PM sensors plus an open platform and API for community measurements, aimed at filling air-data gaps in low-resource regions. Addresses the community/neighborhood-resolution air monitoring requirement with open data; a network/data-platform project more than a single build-it-yourself node.
