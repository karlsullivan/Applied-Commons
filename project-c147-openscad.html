This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Free open-source 'programmer's' solid 3D CAD tool (Linux/Windows/macOS) for parametrically designing custom parts, fittings, jigs and spares that can then be 3D-printed, milled or cut. It lets a trained local operator design locally-procurable replacement components rather than depend on closed OEM parts. Mature, with documented manuals (Wikibooks) and community libraries of building blocks.
