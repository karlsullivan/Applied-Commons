Modbus is the open, royalty-free control protocol supported by almost every pump drive, inverter, meter and PLC, including open ones (openHAB, Home Assistant and OpenPLC all speak it); a USB to RS-485 adapter costs about US$12. Plain Modbus has no authentication, so its safety rests on network isolation, a watchdog with a safe state, and hard-wired interlocks, all now in the text.

Specification

Control and readout of actuators and controllers (pumps, valves, treatment and microgrid equipment) use Modbus per the Modbus Application Protocol Specification V1.1b3. Serial: Modbus RTU on two-wire RS-485 per the Modbus over Serial Line Specification V1.02: 19200 baud, even parity, 1 stop bit (8E1) by default, 9600 baud supported; no parity only with 2 stop bits (8N2). The trunk is daisy-chained with 120 ohm termination at both ends and one pair of line bias resistors; at most 32 devices without a repeater; isolated RS-485 transceivers on outdoor or long runs. TCP: Modbus TCP on port 502 only inside an isolated control network with no route from client Wi-Fi or the internet; anything crossing a shared network uses Modbus/TCP Security (TLS 1.2 or later, X.509 certificates, port 802) or a VPN. Register map, as zero-based protocol addresses: holding register 0 command (0 stop, 1 run); holding register 1 setpoint (scaled integer, unit and scale in the module's documentation); input registers 0-3 voltage (0.1 V), current (0.01 A), power (W) and state code; discrete input 0 fault, 1 fail-safe active. Safety: every actuator has a communication watchdog: if no valid write arrives within its configured timeout (default 10 s), it goes to its documented safe state (for example pump off, or valve closed or open as the process requires). Interlocks, limit switches and emergency stops are hard-wired and local and never depend on Modbus. Writes are accepted only from the configured master. Dashboards get telemetry through the gateway on MQTT (ac-mqtt-iot-bus); Modbus itself is not exposed beyond the control network.
