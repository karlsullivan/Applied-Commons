This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Lightweight open-source (Django + Leaflet) tool to create and embed shareable OpenStreetMap-based maps in minutes; mature (since 2015, 1.5k+ stars). Used for rapid community and emergency/disaster situational maps and dissemination on low-tech channels, complementing the heavier field-collection and photogrammetry tools above.
