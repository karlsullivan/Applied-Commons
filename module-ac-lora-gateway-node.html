This is a draft module. It has not been built or tested.

Community-owned LoRaWAN gateway and network server that ingests low-power sensor telemetry (flood level, weather, market, health) where commercial cellular backhaul is absent; provides the last-mile sensing backbone that feeds the early-warning and advisory platforms.
