This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

An open-source (GitHub) automated water-pump control system for a photovoltaic + battery setup that runs a pump based on battery voltage, sunlight level and tank max-level sensor readings. Directly relevant to the water and dry-season irrigation requirements - power a solar borehole/pump delivering water to the household premises or a smallholder plot - using off-the-shelf PV plus a simple, locally repairable microcontroller rather than diesel, with public code and wiring that are serviceable with common tools.
