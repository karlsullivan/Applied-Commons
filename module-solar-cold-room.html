This is a draft module. It has not been built or tested.

Small off-grid solar-powered cold room for a smallholder harvest or market node, so perishables survive farm-to-market time. Built per the Efficiency for Access low-carbon blueprint, using natural, locally available insulation (reported to cut embedded GHG by ~63% and cost by ~20% versus polyurethane-panel cold rooms). Serves the food preservation requirement (R5) for the small-farm and community-facility scenarios. Reuses the existing corpus code solar-cold-room.
