Peer-reviewed, low-cost, easy-to-assemble neonatal incubator for LMICs, controlled by an Arduino Nano. Maintains temperature (PI control via heater+fan) and relative humidity (bang-bang via ultrasonic nebulizer + dehumidify fan), continuously monitors newborn weight, provides a bed with 0-12 degree tilt, and decouples internal (audible) from external (audible/visual) safety alarms so a caregiver cannot ignore an alarm by stepping away. Design and software build files published open source (GPL v3) for local fabrication. Reported hardware cost 236.7 EUR (reducible to 162.5 EUR).
