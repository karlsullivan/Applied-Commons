This is a draft module. It has not been built or tested.

Open siting and monitoring tool for nature-based coastal defence and blue-carbon baselines: multi-date (historical + contemporary) mangrove distribution maps and dynamics (loss, persistence, gain) via a three-module Google Earth Engine workflow - (1) ROI + Landsat compositing, (2) spectral classification + accuracy assessment, (3) dynamics + qualitative accuracy assessment - combining local coastal-manager expertise (user-drawn classification reference areas) with cloud compute, for non-specialist users.
