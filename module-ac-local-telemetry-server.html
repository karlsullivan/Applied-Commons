This is a draft module. It has not been built or tested.

Open, locally-run, offline-first edge data platform that hosts the local MQTT v5 broker, durably stores continuous environmental/energy telemetry, serves it (dashboard / REST / CSV), and receives LoRaWAN node uplinks - the shared data backbone for a household or village.
