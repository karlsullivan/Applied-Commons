This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

MIT-licensed complete 30-day build plan for an off-grid, low-cost (USD 1,800-2,750) modular plastic processing/recycling lab: ultrasonic cleaner, shredder/sorter, filament maker, pyrolysis reactor, PET chemical-recovery unit, plasma carbon converter, and mold press, with Python planning/simulation models (power sizing, yield, cost/BOM). Garage-scale, solar-ready, no grid or municipal systems. Young (created 2025, 1 star) and self-described as a proof-of-concept/prototype with unverified output projections, but fully open and locally buildable.
