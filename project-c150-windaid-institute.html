This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

501(c)(3) that runs a hands-on renewable-energy technician programme in rural Peru: participants fabricate wind-turbine parts (blade, rotor, stator, tower, base) and install solar panels and service existing turbines for local communities; certificate on completion, financial aid available. A local, build-and-maintain technician pipeline (paid-volunteer model, ~$1,700/2 weeks).
