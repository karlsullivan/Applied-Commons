This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Apache-2.0, free open-source GPS tracking platform (Java back-end): supports 200+ GPS protocols and 2000+ device models out of the box, works with any major SQL database, REST API, web dashboard and mobile manager app; can be self-hosted for free. ~8.1k stars, active 2026-11-10. Open, self-hosted, low-cost tracking of vehicles/assets/consignments for fleets and NGOs (a software layer, not a physical carrier).
