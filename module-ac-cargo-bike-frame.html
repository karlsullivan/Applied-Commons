This is a draft module. It has not been built or tested.

Parametric human- or pedal-assisted cargo vehicle frame for last-mile goods in village/homestead/small-farm scenarios. Base: OHO Tricycle Cargo Bike (CERN-OHL-W 2.0) with the pwnage101 parametric long-john 'upcycled' layout (CERN-OHL v1.2) as the low-cost variant. It is the common carrier: the EV powertrain, the telemetry node, the 24 V swap-bay pack and a cold-chain box (reusing the existing ac-msupply-coldchain-monitor) all mount on its 100 mm frame grid.
