This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

MIT-licensed open-source control software (C11 core + QNX 8.0 real-time build + Python benchmark/simulator) for titrating oxygen (FiO2) for preterm babies on low-cost CPAP, with per-baby safe-state fallback when a sensor, cable or its own software fails, and a nurse-station UI; one board can hold several babies in the safe oxygen range. Targets the stretch requirement of preterm survival beyond warmth (breathing-difficulty management). Open code with CI/tests, offline at point of care (no cloud); a software add-on to a low-cost CPAP, so climate-agnostic and usable year-round in cold climates. Requires an oxygen/CPAP hardware substrate.

  4. Titra C control core - velocity-form PI titration in the 91-95% band with rate-limits, hysteresis and explicit HOLD/FALLBACK state machine raw.githubusercontent.com
  5. Titra QNX security policy - kernel-enforced isolation: llm_t/advisor_t/station_t have no channel-connect to any oximeter or blender driver and no network/spawn raw.githubusercontent.com
