This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open, offline-first, self-contained (single HTML file, no framework/CDN/account/server) mastery-based training module on resuscitation and stabilisation of the newborn at birth, written to the 2025 AHA/AAP neonatal resuscitation guidelines and ILCOR 2025 CoSTR. Dual 'ideal setting' and 'resource-constrained setting' tracks, scalable SVG algorithms (each with a text version), spaced-retrieval items, and an offline certificate/verification flow. Runs with no internet from GitHub Pages or a local file (works on a phone in aeroplane mode). Directly supports the requirement that a trained midwife/CHW can operate resuscitation for birth asphyxia; supports the resuscitator-OPERATION skill side (complements an open-hardware bag-mask, which was not found). Offline, so usable in any climate.
