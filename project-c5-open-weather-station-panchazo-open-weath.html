This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source weather station on Arduino + Ionic (Apache-2.0, 72 stars) that measures outdoor temperature, humidity, pressure etc. and exposes them via a local dashboard — the low-cost sensing layer for the weather-protection / outdoor-side data that drives shelter and thermal decisions.
