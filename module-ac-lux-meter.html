Sleep-zone ambient light (lux) meter

This is a draft module. It has not been built or tested.

Cheap, locally-buildable, open ambient-light (lux) meter (MCU + BH1750-style I2C sensor, USB-C powered) that measures night light in a sleeping room against the <1 lux blackout target and emits an ac-sleep-env-verification record over ac-mqtt-iot-bus. A US$10-20 build that verifies the ac-sleep-blackout-system with no proprietary hardware.
