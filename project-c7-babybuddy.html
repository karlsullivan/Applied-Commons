This project is under research: Applied Commons has catalogued it but has not written a build pack for it.

Self-hosted, open-source (BSD-2-Clause, ~2.9k stars, active 2026) web app that helps caregivers track infant sleep, feedings and diaper changes and learn/predict a baby's needs. Self-hosted = low-cost, locally buildable/maintainable; helps parents and new caregivers improve infant and their own sleep routines.
