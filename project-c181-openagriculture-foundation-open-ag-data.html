This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source agricultural software and open data standard. The device software coordinates control loops and sensor/actuator interactions on-device (with a local UI/API and MQTT-based IoT communication) for growing-environment and irrigation-style control; the Open Ag Data Alliance defines an open standard for interoperability and farmer-owned agricultural data. Provides open, open-data soil/environment sensing and control for food production.
