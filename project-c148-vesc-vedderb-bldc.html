The canonical open-source BLDC motor-controller firmware stack (bldc, 3,581 stars, pushed 2026-11-16; companion vesc_bms_fw, 343 stars) underlying thousands of e-bikes and small EVs. Complete source plus toolchain is what makes an electric cargo tricycle or e-rickshaw repairable by a local workshop with generic off-the-shelf parts. Caveat: no license file at the repo root as of this check (GitHub license API 404, root listing checked) - verify licensing terms before embedding in a product.
