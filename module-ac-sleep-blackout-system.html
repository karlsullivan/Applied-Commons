Sleep-room blackout system

This is a draft module. It has not been built or tested.

Locally-buildable, passive blackout window treatment (tension rail + blackout fabric + foam perimeter seal) that holds a sleeping room below the 1 lux night-light target using local fabric, rail and seal, assembled with hand tools only. No powered components; the design is fully open (CERN-OHL-S-2.0 hardware, CC BY-SA 4.0 build docs). It ships as a barrier plus its build pack, not a meter; achieved light is checked separately with an ac-lux-meter or a phone light-sensor reading.
