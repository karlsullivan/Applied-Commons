This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-hardware project (hardware under CERN-OHL-S-2.0, software MIT) providing a hand-pumped hydraulic press with printable mold geometry for silver-treated ceramic pot filters, plus a QC flow-rate test jig. Includes requirements, sizing calcs, a prototype build plan, design decisions, a general-arrangement drawing, and an interactive 3D model; DOI-archived and REUSE-compliant. Positioned as TRL 3 (paper proof of concept) with a value-engineering target of ~$1,060 USD - a newer, more formal open-hardware build-out of the same ceramic pot-filter treatment path, suitable for small workshops that want to standardize pot-filter production and quality control.
