NeedsClothing and bodily protection
LicenceCERN-OHL-S-2.0
This is a draft module. It has not been built or tested.

Valveless particulate respirator (dust, smoke, PM2.5) for household, small-farm and facility use; the printed body takes standard particulate filter media so the filter interface is swappable.
