This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

A free and open-source PassivHaus design project: open TypeScript source on GitHub, a parametric default design (the 'Lindelund' design, in a Nordic/cold-climate context), and a public site (PassiveOpen.com) where users clone/fork and re-parameterize their own super-insulated passive house. COLD-CLIMATE: PassivHaus is the canonical low-energy solution for long-freezing-winter regions. Young (1 star, created 2022, work-in-progress) but genuinely open and low-embodied-carbon in intent.
