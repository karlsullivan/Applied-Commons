This project is discovered: Applied Commons has catalogued it but has not written a build pack for it.

Open-source (Apache-2.0) solar charge-controller and battery-management (BMS) firmware with open hardware designs, plus an open educational resource for building DC energy systems (project is based in Hamburg, Germany per its GitHub org). Powers field compute and storage from small off-grid solar-plus-battery systems. Active (charge-controller firmware pushed 2026-11; BMS firmware pushed 2026-11). Cold-climate fit: off-grid solar-plus-battery sizing for low-sun/winter conditions; no retrieved source documents a specific Nordic deployment, so treat that as unverified.
