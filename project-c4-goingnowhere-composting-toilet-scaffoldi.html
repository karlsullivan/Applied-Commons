This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Public GitHub repo of Python generative-design scripts that produce the design components, full design and costings for scaffolding-based composting toilets and urinals; low-cost, volunteer-buildable, sealed, liquid/solid separation. Public code but no license declared (not formally OSS); young (created 2024-12, pushed 2025-02).
