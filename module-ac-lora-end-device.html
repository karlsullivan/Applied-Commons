This is a draft module. It has not been built or tested.

Affordable, low-power, off-grid LoRa end device that runs without cell towers, WiFi or internet: last-mile early-warning receiver and peer-to-peer messaging for the unconnected, plus an optional sensor node that can uplink to the LoRaWAN gateway. AES-256 encrypted, several-km range.
