This project is under research: Applied Commons has catalogued it but has not written a build pack for it.

CERN Open Source Hardware License v1.2 (registered with OSHW Foundation) biogas-digester drawings plus an Excel sizing spreadsheet that computes digester dimensions from your inputs. Processes organic/human waste anaerobically into biogas (cooking fuel) plus fertilizer. Open, documented, self-sized, locally buildable; early-stage but complete.
