NeedCold chain and storage
StatusDiscovered
LicenceNone found
This project is discovered: Applied Commons has catalogued it but has not written a build pack for it.

Zero-electricity evaporative cooling chamber with free public design documentation (forced-air, local materials) for short-shelf-life produce. Fits the brief's zero-electricity tier and is distinct from the already-listed ZECC/zeer; wet-bulb-limited, so suited to hot-dry climates, which the brief itself frames as evaporative cooling's realistic envelope.
