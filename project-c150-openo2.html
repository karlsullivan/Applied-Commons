OpenO2

This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source oxygen programme for low-income countries providing repair manuals, training materials and replacement parts for obsolete oxygen-concentrator models, some built under an open design framework with locally available materials; OpenO2 Mobile serviced 2,400+ concentrators across Malawi (2023-24). Directly addresses oxygen-competence and reliable oxygen availability in LMIC facilities. Documented and active.
