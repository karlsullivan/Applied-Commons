This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source project designing an electric vehicle from scratch, with all PCBs in KiCad, 3D models in FreeCAD, and firmware in C using the ESP-IDF framework on RISC-V ESP32-C3 microcontrollers, plus Sk8 (electric skateboard) and Scoot (scooter/bike) configurations and per-component documentation. GPL-2.0 licensed. It provides open electrical/control electronics relevant to the brief's open-firmware requirement but is early and single-contributor (created 2021, ~2 forks, no active community), and is an electronics platform rather than a complete rated last-mile vehicle.
