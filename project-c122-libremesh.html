This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source modular framework for building OpenWrt-based firmwares for wireless mesh nodes, paired with the open-hardware LibreRouter (fully documented, modifiable, redistributable hardware) designed so rural/isolated communities can manage their own wireless mesh with or without internet. Mature community project with real deployments (Antennine/Bologna, Calafou/Catalonia, Coolab/Brasil, Janastu CowMesh in rural Karnataka). Provides a low-cost, locally buildable/maintainable connectivity layer for the last mile.
