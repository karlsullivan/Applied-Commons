This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Free topographic map generated from ODbL-licensed OSM data plus SRTM elevation, styled after official surveying maps with contour lines, hillshade and hiking-specific symbols (tracks, SAC T-class footpaths, huts, water sources); CC-BY-SA, with the open-source style on GitHub and volunteer-run tile service plus automatic Garmin map exports for offline navigation in Basecamp/QMapShack. Data up to 4 weeks behind OSM; render server re-hosted 2026-01-05. A low-cost, documented path to offline contour basemaps for rural, mountain and cold-climate route planning; caveat: small volunteer (no-SLA) project.
