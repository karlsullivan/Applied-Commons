This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Free, open-source tool that provides JTAG/SWD on-chip debug and flashing access for ARM, MIPS and other embedded cores. It is the key to breaking the diagnostic-software half of the repair monopoly: independent repair of the microcontroller- and PLC-based controllers that run pumps, charge controllers, medical and energy equipment, without OEM tooling. Mature (0.12.0 release line), well documented, used across embedded electronics repair. Cold-climate workable (software + cheap probe hardware). Not in already_known.
