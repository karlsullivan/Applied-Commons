This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source (Apache-2.0, ~31 stars, 2026) iOS, on-device, no-subscription 'Whoop-style' readiness tracker built on the Google Health API (Fitbit Air). Helps iOS users monitor daily readiness/recovery without a paid wearable subscription.
