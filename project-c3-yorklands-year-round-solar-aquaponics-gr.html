This project is discovered: Applied Commons has catalogued it but has not written a build pack for it.

2019 design/report for a small solar year-round aquaponic greenhouse in a northern climate, targeting ~1/10 the energy of a conventional Leamington-Kingsville greenhouse. Includes full build and costing appendices, thermal-performance simulation at three Ontario locations (Mount Forest, North Bay, Windsor), and a natural-gas backup sized to activate below 13C; contains an 'About the Designer - Open Source Design' section. Cold-climate (Canada). Maturity: detailed open design proposal with costings, not a documented completed build.
