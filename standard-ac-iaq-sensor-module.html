Indoor air-quality sensor module data interface

Indoor air-quality sensor module data interface
Codeac-iaq-sensor-module
Kinddata
StatusApproved
ApprovedNovember 2026

ISO 16000 is the ISO indoor-air series, EN 16798-1 sets the indoor environment parameters, and the WHO air-quality guidelines are free and authoritative; a fixed channel set with explicit units and a reference per channel makes the heterogeneous ESP32 monitors (AirGradient, Sniffer, HALO, Project Aura AQ, Open AIR) interchangeable and comparable to health thresholds where a threshold exists. Fills a data gap no existing standard covers.

Specification

Shared data interface for indoor air-quality sensor modules. One JSON telemetry object per reading: sensor_id; ts (ISO 8601 / RFC 3339 UTC per ac-iso8601-timestamps); and a fixed channel set, each channel as {value, unit, quality (ok|suspect|faulty), sensor_model, calibration_state}. Channels and their references: PM2.5 and PM10 in ug/m3 mass concentration (measurement method for PM2.5 ISO 16000-37:2019; for PM10, which has no ISO 16000 indoor method, the gravimetric reference method of EN 12341; reference values from the WHO global air quality guidelines, 2021; low-cost optical sensors report against these methods through their calibration_state); CO2 in ppm (EN 16798-1:2019 indoor environment categories); TVOC in ug/m3 (ISO 16000-6:2021, mass-based), or in ppb only with its stated temperature and pressure basis and calibration gas so it converts to ug/m3; a sensor that reports only a manufacturer VOC index sends it as voc_index, flagged as not comparable to any threshold; optional temperature (degC) and relative humidity (%) per EN 16798-1:2019. Optional channels for pollutants in the WHO guidelines for indoor air quality: selected pollutants (2010) - carbon monoxide (mg/m3), nitrogen dioxide (ug/m3), formaldehyde (ug/m3) and radon (Bq/m3) - are compared with those guidelines only when the module carries such a sensor; the other pollutants in that list are not covered by this interface. Assessment follows the procedure of ISO 16000-41:2023, which defines no class boundaries; limit and guide values are taken per country from the WHO guidelines and EN 16798-1. The reporting cadence (default 30 s) is a module choice, planned per ISO 16000-1:2004. Transport is the existing ac-mqtt-iot-bus or ac-lorawan-uplink, so no new radio layer is introduced. The JSON field names and shape are AC's own; the cited standards validate the units, methods and pollutant choice, not the wire format.
