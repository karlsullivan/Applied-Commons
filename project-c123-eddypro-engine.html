This project is discovered: Applied Commons has catalogued it but has not written a build pack for it.

LI-COR open-source core engine that processes eddy-covariance data into fluxes of CO2, water vapour (evapotranspiration), methane, and energy — the standard method for measuring ecosystem carbon exchange. Directly addresses the stated gap of 'no low-cost, open way to verify durable storage' by giving communities an open MRV tool for forest/soil carbon flux. Originated from the EU IMECC ECO2S project; cross-platform, buildable from source. Maturity: established and widely used; the eddypro-engine repo is tagged GPL-3.0, though the project README notes EddyPro 7 now ships under a free EULA that restricts use by other commercial organisations (earlier versions remain GPL-3.0) — a licensing caveat worth flagging.
