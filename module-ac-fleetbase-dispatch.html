Fleetbase (fleetbase/fleetbase, AGPL-3.0) is a modular logistics-and-supply-chain operating system (LSOS). Run as the dispatch/routing/tracking layer that consumes vehicle telemetry (position, battery, cargo temperature) and ODK fleet logs, then emits stop sequences and status for the village / homestead / small-farm / community-facility scenarios. Documented and active (4390 stars, pushed 2026-10-23).
