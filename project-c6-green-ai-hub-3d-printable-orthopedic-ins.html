This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

MIT-licensed software stack to collect pedobarographic and user data and train a custom model to predict orthopedic insole parameters for 3D printing. For users needing custom-fit insoles; moderate maturity (15 stars, actively pushed 2026), research-grade.
