This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

QGIS plugin that lets disaster managers and humanitarian agencies model realistic natural-hazard impact scenarios (floods, earthquakes, tsunamis, cyclones, etc.) for planning, preparedness and response, producing risk maps and damage/affected-population estimates from open data. Directly serves the need brief's 'open hazard-exposure and vulnerability layers' requirement by running entirely on open, locally-held data with no vendor. Who it helps: national/local disaster-management agencies and humanitarian responders. Maturity: long-running humanitarian project, GPL-3.0, ~285 GitHub stars, active (last push Oct 2026).
