This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open code (Blue Ventures Conservation, 71 stars) for multi-date mangrove distribution and dynamics mapping on Google Earth Engine, designed to combine local coastal-manager expertise with cloud compute. Supplies the site-specific blue-carbon and habitat baselines the brief requires before siting nature-based coastal defence.
