This project is discovered: Applied Commons has catalogued it but has not written a build pack for it.

World Resources Institute open-source (GPL-3.0) machine-learning method that segments 'trees outside of forest' from Sentinel-2 imagery, distinguishing non-forest tree cover (agroforestry, urban trees, restoration plantings) from intact forest. Helps verify reforestation/restoration outcomes and monitor tree cover — addressing the 'planting with little verification' gap. Well-developed (182 stars, last push 2026-09-08). Distinct from the already-known GFW carbon-budget framework and GEM mangrove methodology.
