This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

A library of open-source, OpenSCAD-defined clean-cookstove reference designs plus 3D-printed DIY jigs for massive, low-skill deployment: a Fresnel 'Ring-Ring' concentrating solar cooker, a beverage-can alcohol stove (40-60%+ efficiency vs 10-15% for open fire), and a brick / fire-protection-panel rocket biomass stove, all using off-the-shelf commodity materials and standard hardware. Targets the ~2.7B people cooking on solid fuels; the design is published (IEEE 7343973) and explicitly open, encouraging both humanitarian and commercial use.
