This project is under research: Applied Commons has catalogued it but has not written a build pack for it.

Open Source Ecology's Power Cube: a self-contained engine-driven hydraulic power unit meant to power several Global Village Construction Set machines through quick couplers. Production library design audit AUD06 (shared hydraulic power): inspect the Power Cube VII files and their compatibility, and compare one shared power pack with independent drives for real equipment use.

Evidence

The strongest findings from Applied Commons research on this project:

  • No frame-drawing file is missing or a dead link on the v7 page: all 25 files referenced by Power_Cube_VII (PCVII_frame.pdf, PCVII_Fabrication.pdf, BOM, main .skp, all module .skp's, all module PDFs, wiringharness.png, etc.) resolve live over HTTPS (HTTP 200) via Special:FilePath. The incompleteness is a content defect, not a missing-file defect.
  • The v7 Files table has a copy-paste error: the 'Wiring Harness' row links to Frame.skp instead of the wiring-harness drawing (the actual drawing is wiringharness.png, referenced in the Wiring Harness section).
  • 3000 PSI / 15.2 GPM is the Power Cube VII's own published rated point, on a 28 HP Briggs & Stratton Professional Series gasoline engine with a 7-gal fuel tank and a fixed-displacement pump.
  • The only 'drawing' cited by the v7 Frame Module (PCVII_frame.pdf, 1 page, 182 KB, scanned image) is a 3D CAD wireframe/isometric render of the frame cage - no title block, no dimensions, no weld callouts, no parts list. It is a model picture, not a fabrication drawing, so it cannot be used to cut or weld the frame.
  • The v7 Frame Module gives the frame as a terse 10-bullet step list (cut angle iron/flat bar/rebar/expanded steel, grind 45-degree ends, bend rebar into U-shaped hoist hooks, weld hoist hooks and QA plates) with no member dimensions, cut sizes, wire gauges, or weld schedule in the text. The only dimensioned frame text on the OSE wiki (29"/27"/24" angle-iron lengths) is on a separate, unlinked page (PowerCube_Frame).
  • PowerCube_Frame, the only dimensioned v7 frame text on the wiki, is not linked from the v7 page and covers only the base angle-iron cube skeleton (3 steps + 3 photos + a welding video). It does not cover the v7 frame's rebar hoist hooks, expanded steel, QA plates, battery box, or fuel-tank/reservoir supports, so it is not a complete v7 frame fabrication package.
  • There is no single authoritative 'current' v7 release: the v7 page is frozen (last design updates Oct 2014), the 2018 Power_Cube_Library page declares 'current version is Power Cube v15.6', and the community GitHub mirror (Witz0/OSE-Power-Cube, last push 2018) carries v17.08/v17.11/v18.01 FreeCAD frame files but no v7. The Power_Cube/Assembly_Instructions page is stale (last edited 24 Jul 2011, points to a ~2011 50-min Vimeo build video).
  • An independent first-time builder working from the published v7 files alone cannot be expected to complete the frame - the structurally most critical, dimensionally demanding part - without live remote or in-person direction. The fabrication-grade frame drawing is effectively absent (a 3D render stands in for it) and the dimensioned frame text is fragmented across an unlinked, incomplete page.
