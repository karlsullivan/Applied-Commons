This project is parked: Applied Commons has catalogued it but has not written a build pack for it.

Open Source Ecology's Power Cube: a self-contained engine-driven hydraulic power unit meant to power several Global Village Construction Set machines through quick couplers. Production library design audit AUD06 (shared hydraulic power): inspect the Power Cube VII files and their compatibility, and compare one shared power pack with independent drives for real equipment use.

Evidence

The strongest findings from Applied Commons research on this project:

  • No frame-drawing file is missing or a dead link on the v7 page: all 25 files referenced by Power_Cube_VII (PCVII_frame.pdf, PCVII_Fabrication.pdf, BOM, main .skp, all module .skp's, all module PDFs, wiringharness.png, etc.) resolve live over HTTPS (HTTP 200) via Special:FilePath. The incompleteness is a content defect, not a missing-file defect.
  • The v7 Files table has a copy-paste error: the 'Wiring Harness' row links to Frame.skp instead of the wiring-harness drawing (the actual drawing is wiringharness.png, referenced in the Wiring Harness section).
  • PowerCube.skp on the OSE wiki is a binary SketchUp 8.0.0.11751 3D-model container (8,822,025 bytes, uploaded 2011-12-26 per MediaWiki imageinfo), not a drawing package - it holds solid geometry, not fabrication drawings, hole patterns, or weld schedules.
  • The public v15.6 documentation still self-declares it is not fabrication-ready, verbatim and live on the wiki: 'NOTE: This document is still under development and is not ready yet for "Prime Time" fabrication. This note will be removed when it has reached a "comfortable" level of completion.'
  • v15.6 specs live on the wiki: 28 HP Briggs & Stratton Professional Series engine, 4" x 4" tubular steel frame, max pressure 3000 PSI, max flow 15.2 GPM, 7 Gallon fuel capacity, approx 400 lbs. Genealogy: 6 units built at the July 2015 Power Cube Workshop, one tested with a gasifier, dimensions 9x9x8 measured in number of holes.
  • The OSE Power Cube produces hydraulic power only: an engine coupled to a hydraulic pump delivering high-pressure fluid via quick-connect hoses. No electrical output port, generator, or alternator is documented on the Power Cube itself.
  • The Micro Power Cube is NOT an electrical-output path: it is a 1-cubic-foot electric-motor-driven hydraulic pump unit (gen-1 RC 3-phase motor ~1.94 hp with a 1000 W regulated supply; gen-2 AC vacuum-cleaner motor ~1.44 kW) that CONSUMES ~1-2 kW of electricity to drive its hydraulic pump. The question's premise that the Micro Power Cube is the electrical path is inverted.
  • v15.6 is the authoritative, current frame fabrication release: the OSE wiki designates it 'the current version' on both the main Power Cube page ('Note: The current version as of June 2015 is Power Cube v15.6 as under Versions below') and the Power Cube Library page ('Current version is Power Cube v15.6'); the genealogy adds 'Power Cube Library consists of v15.6'.
