The catalogue is only useful if others can build from it. DIN SPEC 3105-1 defines what open-hardware documentation must contain so that anyone can study, modify, make and sell the hardware, and OKH makes it findable by other libraries. The printable PDF and the nameplate mean a built module can always be traced back to its instructions, including offline.

Specification

Every Applied Commons build pack meets DIN SPEC 3105-1 (requirements for the technical documentation of open source hardware) and ships an Open Know-How manifest (okh.yml, Internet of Production Alliance OKH specification) so open-hardware libraries can index it. The pack contains: the bill of materials with part numbers and low-income substitutes; design files in open, editable formats (STEP plus native FreeCAD or KiCad sources, DXF for cut parts, Gerber with the KiCad project for boards, source code); assembly instructions with drawings or photos; the test procedure and its acceptance values; the safety review's controls; the standards it implements, by code; its licence (CERN-OHL-S-2.0 for hardware, GPL-3.0-or-later for software, CC BY-SA 4.0 for documentation, or the source design's licence where it derives from one); and a version number with a change log. A printable PDF of the whole pack is produced with every release, for offline use. Nameplate on every built module: module code and version, licence, ratings (voltage, current or power, pressure, temperature as relevant), protection class and IP rating, maker and build date, a QR code linking to the build pack, and ISO 7010 safety signs and IEC 60417 symbols wherever a hazard exists. A module placed on a market with product-marking rules (CE marking in the EU) follows those rules as well; the nameplate does not replace them.
