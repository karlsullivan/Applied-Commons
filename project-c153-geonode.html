This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source platform for building geospatial information systems and deploying spatial data infrastructures (SDIs): a web-based, OGC-standards-based (WMS/WFS/WCS/WMTS/CSW) content management system for publishing, searching, styling, sharing and administrating vector and raster data with fine-grained permissions and REST APIs, on a Django base. Who it helps: governments and institutions that want a self-hosted, vendor-free portal to hold and serve open (ODbL-equivalent) map/data assets locally — the 'locally owned, reusable' requirement. Maturity: an official OSGeo Community Project, stable release 5.1.1, GPL-licensed, ~1.7k GitHub stars, active (Nov 2026).
