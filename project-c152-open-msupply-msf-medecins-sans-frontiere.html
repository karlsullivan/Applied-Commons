This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open mSupply is the world's leading open-source Logistics Management Information System (LMIS) for publicly managed health supply chains, used in 30+ countries for 20+ years (Rust server on SQLite/Postgres + React web/desktop/Android client + offline-first mobile). Its cold-chain suite -- the msupply-cold-chain Android app with BlueMaestro/FridgeTags Bluetooth temperature sensors, the Conforma vaccine IRIMS (immunization register/inventory management), and the temperature-sensor crate -- is purpose-built for the exact documented failure mode in the brief: continuous 2-8 C fridge monitoring, excursion recording/alarms, and calibration of the sensor layer (the cheap high-value gap) rather than just the fridge. Climate-agnostic software, so it runs year-round in cold climates (UK, Scandinavia, Canada, Alaska) as well as SSA. Caveats: it is monitoring/management software, not a refrigeration unit or power source; and its core is under a custom 'mSupply Open Source License' (AGPL-3.0 extended with geographic low/middle-income terms), not plain MIT/GPL -- confirm terms before relying on it.
