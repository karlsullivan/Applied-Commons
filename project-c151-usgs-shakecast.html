This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source system from the USGS that generates real-time earthquake shaking estimates and early-warning 'shakes' from felt reports and station data, with related open repos (shakelib, shakemap-scenarios, shakecast-aebm) in the same USGS GitHub org. Supports last-mile seismic hazard/early-warning data infrastructure. Note: the shakecast repo was last pushed 2024, so it is less active than the top candidates — included for its open early-warning/shaking-estimation capability.
