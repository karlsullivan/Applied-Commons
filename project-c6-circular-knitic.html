Last updated upstreamFebruary 2022
This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-hardware circular knitting machine (laser-cut and 3D-printed parts, MIT-licensed) for making tubular knitted garments. For makers building knitting equipment; reasonably mature (235 stars, 43 forks) and documented.
