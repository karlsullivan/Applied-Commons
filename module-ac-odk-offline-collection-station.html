This is a draft module. It has not been built or tested.

REUSE of the existing ODK module (Apache-2.0), extended with a fleet-logging variant. ODK Collect on ordinary Android phones records vehicle check-ins, cargo manifests, stops and geotagged photos for last-mile and community delivery (village / homestead / small-farm / community-facility scenarios); Central is self-hosted and works offline, syncing when a link appears. The same Collect form authoring used for surveys is re-used for cargo/dispatch logs, so one toolchain serves both.
