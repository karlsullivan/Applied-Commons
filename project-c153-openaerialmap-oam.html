This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open platform run by the Humanitarian OpenStreetMap Team that hosts, shares and serves openly-licensed satellite and drone imagery for humanitarian mapping (used for Nepal 2015, Turkey-Syria 2023, Myanmar). Being rebuilt with Development Seed on a STAC-based open stack (COG, pgSTAC, TiTiler) so local instances can index imagery from open providers; 5,000+ users and 100+ images/month. Closes the open-imagery-access gap that UNOSAT-EMS otherwise monopolises.
