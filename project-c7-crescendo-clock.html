This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source (MIT, ~43 stars, created 2022, active 2026) ESP32 alarm clock that wakes you gently with a crescendo alarm; rotary-encoder control, WiFi/WPS, 3D-printed case, light sensor, Home Assistant MQTT integration. Low-cost, locally buildable; helps people improve sleep hygiene with a gentle, open wake-up device.
