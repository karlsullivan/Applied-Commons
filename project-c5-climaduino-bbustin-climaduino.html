This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Arduino open-source thermostat with humidity control using the DHT22 sensor (GPL-2.0, 26 stars) — a minimal, cheap, locally-buildable closed-loop temperature and humidity controller and a good minimal reference design for DIY thermal-comfort hardware.
