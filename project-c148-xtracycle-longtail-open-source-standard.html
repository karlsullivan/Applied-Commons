This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Longtail cargo bike (extended rear wheelbase, ~100 kg capacity, ~1 m3 class per the cargo-bike literature) that Xtracycle documented as an open-source standard in 2008, which enabled DIY builds such as the Xtravois. Pedal-powered with commodity bicycle parts, a classic year-round cold-climate carrier in Scandinavia and the northern US where pedal power outperforms a degrading battery. Caveat: the open-standard fact is verified from the retrieved Wikipedia 'Cargo bicycle' article; the vendor site could not be fetched from this machine, so a primary vendor URL is not attached.
