This is a draft module. It has not been built or tested.

Local data platform that aggregates community-generated data (ODK/Kobo survey submissions, Ushahidi reports, Kiwix usage, sensor telemetry) and serves it over the local mesh (REST + static maps) for local analysis and transparency, with periodic upstream sync. Self-hosted, community-governed.
