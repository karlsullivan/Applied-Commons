This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Modular, open-source G-code interpreter and CNC controller (C++, GPL-3.0, active) that runs on cheap ARM single-board computers (Raspberry Pi and similar). Lets a local operator build, wire, repair or reprogram a CNC milling machine with self-hosted, vendor-free control software instead of a closed controller.
