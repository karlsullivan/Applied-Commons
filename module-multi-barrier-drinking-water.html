This is a draft module. It has not been built or tested.

Single no-power, locally buildable household package: biosand/slow-sand filtration (turbidity + bacteria), a dedicated disinfection step (viruses/protozoa), and a chemical-removal option (fluoride/arsenic) via GAC/ion-exchange; closes the core need-brief gap no single current household tech covers.
