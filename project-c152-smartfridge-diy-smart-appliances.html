This project is discovered: Applied Commons has catalogued it but has not written a build pack for it.

GPL-3.0 open firmware/software for a smart refrigerator on ESP32 + ESPHome: temperature control and logging for a home or off-grid fridge. Public code, README and images; small project (1 star, active 2026) but a real, buildable, documented open design. Helps households and smallholders run a cheap, controllable, grid-independent fridge. Maturity: early-stage but complete code + license.
