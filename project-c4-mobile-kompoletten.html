This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

A build guide (in German) for modular composting toilets, released under CC0, with drawings in LibreOffice Draw (.odg) and the guide in Writer (.odf). Public, reusable, locally buildable documentation for a toilet system; early-stage, single-language.
