This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source project designing productive, modular, automated, low-power indoor hydroponic gardens that anyone can reproduce. Helps anyone wanting a replicable low-power growing system. Maturity: early/ongoing - the modular lighting system Grow is slated for 2026.
