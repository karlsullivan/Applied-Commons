This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Open-source reference implementations of the Interledger payment protocol (ILP) and the newer Open Payments / SPSP stack (interledgerjs monorepo plus component repos), designed to connect disparate ledgers and wallets so value can move across providers at low cost. It addresses the brief's explicit coping/remittance requirement (end-to-end cost well under the ~6% average, no unexpected fees) by providing a common open rail instead of fragmented mobile-money provider integration. Honest caveats: the monorepo has no single root license file (individual component repos such as ilp-connector, ilp-account-service and ilp-transport-grpc carry Apache-2.0, so the per-component license should be verified before adoption); it is a network/protocol layer, not an offline-first tool; and it is smaller (tens of stars) and less documented than the top five. Include as the remittance-rail candidate, not as a drop-in.
