This project is discovered: Applied Commons has catalogued it but has not written a build pack for it.

The Gasifier Experimenters' Kit (GEK) from gekgasifier.com, documented on the P2P Foundation wiki: an open, modular biomass gasification / pyrolysis platform (downdraft gasifier for clean gas; BEK mode for biochar) in use for DIY, commercial and university research since 2008, with 300+ systems in 40 countries across 50+ universities. Provides an open route to wood-gas for cooking, heat and small-scale power, relevant to cold-climate and remote households that already burn wood, backed by an active forum and quarterly hands-on workshops.
