Open Building Institute
NeedShelter and thermal comfort
StatusScreened
LicenceNone found
Climatesarid, temperate, cold
This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

A non-profit that publishes an open library of building designs, structural modules, and parts under a Creative Commons (CC BY-SA 4.0) license, intended to be adapted and built by communities. A public-designs source for habitable-space and weather-protection structures that can be localized to low-cost, hand-tool construction.
