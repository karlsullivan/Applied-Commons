Finite Volume Community Ocean Model (FVCOM), a 3D coastal/ocean circulation model used for storm surge and coastal flooding analysis. Public code on GitHub under a custom FVCOM Users' License Agreement (not OSI-approved open source). 106 stars, active (pushed 2026-11-06).
