This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Universal open-source grid-forming inverter control library (synchronous-machine emulation in software) with a verifiable model-to-firmware chain, C code intended for direct compilation into inverter firmware, plus PSCAD and Simulink simulation models; aligned with IEEE 2800 and UNIFI. Provides the open grid-forming inverter control layer for microgrids and renewable/battery resources, with a stated goal of becoming a community-governed open standard. Covers safety/infrastructure microgrid control.
