An open-source, 3D-printable general-purpose plastic shredder for mechanically breaking down post-consumer plastic (PET, HDPE, PVC, LDPE, PP) into uniform pieces for local recycling, with the stated goal of empowering communities to remove plastic from their waste stream. The repo carries the full open design: FreeCAD source (OpenShredder.FCStd plus a Cycloidal-Generator macro), 5 STL files for the gearbox, a documentation file on plastic/filament/pellet recycling, and a GPLv3 license, with an active wiki and community issues (8 stars, small but real). It is low-cost and locally buildable (3D-printable), directly on-brief for 'provide local plastic recycling where none exists.' Indoor operation, so cold-climate capable. Note: earlier-maturity project (small star count), so treat build documentation as a work in progress.
