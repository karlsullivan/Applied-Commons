Open-source (MIT, ~109 stars, Pfizer, active 2026) Python package for processing and analyzing inertial/motion-sensor (IMU) data, with explicit algorithms for sleep, gait, sit-to-stand and activity. The analysis layer for wearable motion/actigraphy sleep data; helps researchers and builders.
