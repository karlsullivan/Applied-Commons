This project is screened: Applied Commons has catalogued it but has not written a build pack for it.

Mature personal and small-business double-entry accounting software (GNU GPL, 4,375 stars / 994 forks), volunteer-developed, documented and translated, with Linux/Windows/macOS builds. Runs fully offline, tracks money with professional double-entry principles, and is freely re-runnable. Fits local-language, one-device cooperative and savings-group bookkeeping with no cloud dependency. Runs year-round in freezing climates (pure cross-platform software, no climate-dependent hardware).
