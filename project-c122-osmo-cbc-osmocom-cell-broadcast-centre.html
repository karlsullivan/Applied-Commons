This project is discovered: Applied Commons has catalogued it but has not written a build pack for it.

C-language implementation of a minimal 3GPP Cell Broadcast Centre — the central network element for distributing cell-broadcast and emergency messages to basic feature phones with no data — implementing CBSP plus an HTTP/REST interface for message creation. AGPL-3.0, part of the actively maintained Osmocom open-source GSM stack (which also supplies the low-cost base-station side). Maturity: established open-source project (created 2020, active contributor base, user/Vty manuals), with LTE (SBcAP) support planned. Directly matches the brief's cell-broadcast channel requirement to feature phones.
