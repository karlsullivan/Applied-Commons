This is a draft module. It has not been built or tested.

Self-contained battery-management system for the 48 V DC bus: per-cell voltage and temperature monitoring, active/passive balancing, state-of-charge estimation and over/under-voltage, over-current and thermal protection, with a hardware disconnect for faults. The shared storage-protection block behind every DC-bus system (household lighting, pumping, cold room, health-facility 24/7 power) across all scenarios. Reuses the existing corpus code libresolar-bms.
